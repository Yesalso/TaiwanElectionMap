## 2. 选县市时要考虑的 4 件事

1. **地理相邻、成一区块**：县市之间必须相连（或只有可接受的离岛），否则 bbox 被海域撑大、缩放浪费。  
   反例：把「基隆市」和「花蓮縣」一起选 → 中间隔着半个台湾，县市界/比例尺全部失真。
2. **长宽比决定输出尺寸**：`bbox 宽 km / 比例尺` × `bbox 高 km / 比例尺` 必须都 `< MAX_PX=12000`。
   - 高屏：89.7 × 174.5 km，1px=20m → 4574×8901 px（竖长，宜加图例于右侧）
   - 北北基宜：约 78 × 110 km，1px=20m → 3733×5596 px
   - 6 县市以上或含外岛 → 改 1px=30m（云嘉南高屏即用 30m），否则运行时间与内存暴涨。
3. **数据能不能对上**：先数票数 Excel 里该县市的行数、再数 SHP 里该县市的图斑数（见 §3 步骤②③），  
   精确匹配应 ≥99%，剩下的由异体字/模糊匹配兜底，仍无资料的留白。
4. **选错县市的代价**：改 `TARGET_COUNTIES` 只是一行，但 `DROP_NAN_COUNTIES`、离岛阈值、  
   `EXPECT_CC`、docstring、输出档名、`layer_name` 全都要跟着改 —— 所以宁可一次选对。

## 3. 新增一个县市组合的作业流程（checklist）

- [ ] **① 复制脚本并改名**：`Copy-Item Draw_South2_President_2016.py Draw_XX_N_President_YYYY.py`，  
  `N` = 县市数；docstring 的「执行」「输出」两行同步改。
- [ ] **② 摸清票数 Excel**（工作表 `各里彙總`，栏位 `選舉區別|鄉(鎮、市、區)別|村里別|…得票率`）：
  ```
  python -c "import pandas as pd; d=pd.read_excel(r'2016Precident/data/2016總統副總統選舉_得票率.xlsx', sheet_name='各里彙總'); print(d.groupby('選舉區別').size())"

  确认：行数、无 `%`、无合并村名（`、`）、候选人栏位名称与 `CAND_NAMES` 一致。
  ```
- [ ] **③ 摸清 SHP**：
  ```
  python -c "import geopandas as gpd; g=gpd.read_file(r'…\VILLAGE_MOI_xxx.shp', encoding='cp950'); print(len(g), g.COUNTYNAME.nunique(), g.crs)"

  确认：**编码**（104~107 版 = `cp950`；108 版以后 = `UTF-8`）、**crs**（旧档可能为 `None` →
  `set_crs("EPSG:4326")` 后再 `to_crs("EPSG:3826")`）、各县市图斑数与 Excel 行数量级一致。
  ```
- [ ] **④ 估尺寸**：`bbox宽km/比例尺` × `bbox高km/比例尺`，长宽都 < 12000；过大就 20m→30m。
- [ ] **⑤ 设 `TARGET_COUNTIES`**：注意档名里的县市「包含哪些、排除哪些」要写进 docstring  
  （北北基宜桃 → 北北基宜：刻意排除桃园，说明写在标题括号里）。
- [ ] **⑥ 决定 `DROP_NAN_COUNTIES`**：无村里名的图斑＝港池、航道、潟湖、沙洲水域。  
  是否整笔剔除取决于**该县市无名水域是否会影响区界完整性**：  
  \- 基隆市（基隆港）、高雄市（高雄港）→ **剔除**  
  \- 云林/嘉义县/台南（沿岸潟湖、渔港）→ **剔除**（南六县版）  
  \- 屏东县（东港、枋寮、车城、满州水域）→ **保留填白**（南六县/高屏版）
- [ ] **⑦ 离岛与外海**（`strip_far_parts`）：先量实际距离分布再定阈值，  
  预设 `无名 2km / 有编制 20km`：  
  \- 龟山岛 ≈9km（有编制）→ 保留；基隆屿/彭佳屿（无名，3.3km+）→ 剔除  
  \- 小琉球 12.2~14.8km（有编制、屏东琉球乡 8 村）→ **保留**  
  \- 宜兰大溪里 100 个 120km 外海碎块（图资错误）→ 剔除
- [ ] **⑧ `EXPECT_CC`**：**必须用 `unary_union` 的连通分量数**，不要用 `1 + n_islands`。  
  教训：高雄+屏东的 `n_islands=8`（小琉球 8 村），但 8 村同属**一个**岛 → 真实组件数是  
  「本岛 + 小琉球 + 旗津外海小岛 = 3」。属性式算法会误报自检失败。
- [ ] **⑨ 同名区县陷阱**：区层一律 `dissolve(by=["COUNTYNAME","TOWNNAME"])`，  
  只按 `TOWNNAME` 会把「臺北中正區 + 基隆中正區」等同名区合并，画出跨县市假区界；  
  多县市时**另加 5px 縣市界**才看得出交界（单县市版可省）。  
  **dissolve 后务必接 `remove_ring_slits()`（§5）** 折叠图资自带的退化迴针，  
  否则外环会把瑕疵画成凭空冒出的死线。
- [ ] **⑩ 版面**：`TITLE_LINES=[]` 关标题；图例＝还原 `legend_start_tier` →  
  `legend_stops_list / name_imgs / label_img_cols / group_w / legend_h` →  
  `panel_x = W + 80`、`new_W = panel_x + content_w + 80`、纵向居中 `paste(…, (0,(new_H-H)//2))`。  
  **注意**：存档后自检取地图片段要加 `_off = (new_H - H) // 2` 偏移，否则全图自检失败。
- [ ] **⑪ 跑图 + 全绿**（见 §6），再改 docstring 描述与实际一致。

## 4. 已知的坑

| 坑                  | 症状                          | 解法                                                              |
| ------------------ | --------------------------- | --------------------------------------------------------------- |
| .dbf 编码            | 中文栏位全乱、`UnicodeDecodeError` | 104~107 版用 `cp950`，108 版后用 `UTF-8`；读出来 COUNTYNAME 是乱码就换另一个      |
| `crs=None`         | `to_crs` 直接报错               | `set_crs("EPSG:4326")`（旧档为经纬度）再投影 `EPSG:3826`                   |
| 同名乡镇市区             | 区界跨县、图斑粘连                   | `dissolve` 用双键 `(COUNTYNAME, TOWNNAME)`                         |
| 无村里名图斑             | 港口画成一块突兀的白/色块               | `DROP_NAN_COUNTIES` 按县市决定（§3⑥）                                  |
| 外海碎块               | 地图四周散点、连通分量检查失败             | `strip_far_parts`（无名 2km / 有编制 20km），先量距离再定                     |
| `n_islands` 属性当组件数 | 自检「应为 N」永远对不上               | 改用 `unary_union(...)` 组件数（§3⑧）                                  |
| 同一岛多村              | 把一岛算成 N 个离岛                 | 组件数看几何、不看村数                                                     |
| 图资年份               | 村里名称与选举年对不上                 | 取**最接近选举年**的版本（2016→107/108 版；2020→108 版；111 版仅新资料可用），名称差异交模糊匹配 |
| 控制台乱码              | `卙` 中文、`␉` 输出               | `$env:PYTHONIOENCODING='utf-8'` 后再跑                             |
| 内存/时间              | 慢、或大图爆内存                    | 比例尺 20m→30m；`MAX_PX=12000` 兜底                                   |
| **区层迴针／死线**        | ② 层地图中间凭空冒出粗线，一端接海岸、一端悬空    | `remove_ring_slits`（§5）折叠 dissolve 后残留的退化迴针                     |

## 5. 案例研究：新竹市香山区「迴针死线」的识别、确认与修复

> 这是**图资本身**的数字化瑕疵，不是代码画错。任何用同一份村里界图资 + `dissolve`  
> 出区/县市界的脚本（§1 表中所有 2016 版）都可能中招，做法可整段照搬。

### 5.1 症状

桃竹苗 2016 图的 **② 层（区界 3px + 县市界 5px）** 单独取新竹市渲染后，  
**中间出现两条粗线**，都**一端接海岸、另一端悬空**（死巷），明显不该存在：

| 位置 | 起点 → 尖端                                       | 长度                   |
| -- | --------------------------------------------- | -------------------- |
| 中左 | (238659.5, 2738485.8) → (239669.7, 2737751.8) | 往返 2497m（≈1.25km 单程） |
| 左下 | (239549.5, 2744444.9) → (241572.0, 2743786.1) | 往返 4283m（≈2.14km 单程） |

### 5.2 识别（怎么把可疑线条揪出来）

1. **单层单县市渲染**：不要看全图，只把 ② 层、只取新竹市画出来  
   （`layer_hs_test.png`，821×804px，1px=20m），背景干净才看得出多余线条。
2. **按线宽分类（EDT / skeleton）**：用测地距离变换量每条线的粗细——  
   合法县市界 5px、区界 3px、县内村界 1px。**粗 5px 的线出现在县内部**  
   （周围都是 3px 区界）就是第一个警报。
3. **看端点**：真实边界要么闭合成环、要么两端都接其他边界；  
   **只有一端悬空的"死巷"几乎必是瑕疵**。

### 5.3 确认（怎么证明是图资瑕疵，而不是真实边界）

三层证据逐步锁定：

1. **复现**：用原脚本的同一段代码路径重跑该层 → 与原图**逐像素完全相同**（0 diff），  
   先排除渲染/参数问题。
2. **拆分来源**：把参考图按几何来源拆成遮罩单独渲染——**只画香山区**能重现这两条线，  
   只画北区/东区不会 → 锁定来源是**香山区**。
3. **几何层找退化迴针**：在香山区外环上找「**首尾位移极小（≤5m）但子路径很长（>100m）**」  
   的子路径——它从某点出发沿同一路径走远后又**原路折返**，围出**面积≈0**。  
   真实边界绝不可能原路折返，这两段正是长为 2.5km / 4.3km 的退化迴针。

一句`话：dissolve 把这些迴针残留在香山区外环上，② 层再把外环当「县市界」用 5px`  
画出来 → 就成了那两条粗线。

### 5.4 修复

在 `Draw_TCM4_President_2016.py` 新增 `_despike_ring()` + `remove_ring_slits()`，  
在 `records.dissolve(by=["COUNTYNAME","TOWNNAME"])` **之后**、`clean_tiny_holes()`  
**之前**调用。判准用**三道门槛**并联，兼顾「去瑕疵」与「不误删真实地形」：

| 门槛               | 值        | 作用                           |
| ---------------- | -------- | ---------------------------- |
| 首尾位移 `tol`       | ≤ 5m     | 只折叠「去而复返」的闭口子路径              |
| 子路径长度 `min_path` | > 100m   | 放过正常的小折角，只抓绕一大圈的迴针           |
| 围出面积 `area_thr`  | < 5000m² | **保护真实半岛/岬角/细长沙洲**（它们面积不为 0） |

命中即删除 `i+1..j-1` 的顶点，把迴针折叠成一个点。

**只改区层，不动村里层**：村里层（① 1px）实测 1094 笔**无此瑕疵**。

### 5.5 验证

- **单层 diff**：修正后与原图差异**仅 3 个连通块**＝那两条死线  
  （566px / 330px / 1px 交界点），其余像素完全相同。
- **全域代价**：桃竹苗全跑修正 **25 个线环 / 38 个顶点**，面积最大变化 **0.45m²**，  
  几何全部 valid。
- **全图自检全绿**：② 层 1px 原始线未被覆盖 0px、② 层连通分量 1、油漆桶不变式 0、  
  几何参考差异 610px＝0.0029%、非允许色 0、村外非白 0。
- 对照图：`maps/新竹市_迴針修正前後對照.png`。

## 6. 出图后的 4 项自检（全绿才算完成）

1. **油漆桶不变式**：非线连通区域中「非单色区域」应为 0。
2. **几何参考比对**：与独立的逐像素几何着色（rasterio/GDAL 中心规则）差异 ≈0（容差 `0.0002*W*H`）、  
   **村外非白 = 0**。
3. **② 層散點**：区界层连通分量 **≤ `EXPECT_CC`**（本岛 + 保留离岛；沙洲间水道小于  
   ② 層线宽时 raster 上会并块，故为上限检查），且 `<=40px` 小分量 = 0；  
   ① 層 2x2 粗块 ≈0。
4. **存档后复检**：非允许色 = 0、村外非白 = 0（加 `_off` 偏移后取地图片段）。

预期数字参考（高屏 2016，1px=20m）：票数 1342 行、SHP 1358 斑、精确匹配 1341、无资料 17、
