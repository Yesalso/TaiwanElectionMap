## 2. 與 1996 版的差異（本次全部改動）

### 2.1 候選人：4 組 → 3 組

2000 第十屆登記五組（號次 01~05）：宋楚瑜(01,無黨籍)、連戰(02,中國國民黨)、
李敖(03,新黨)、許信良(04,無黨籍)、陳水扁(05,民主進步黨)。

**本圖只取三強**——李敖、許信良在全國 **任何一個村里都未曾領先**（2000 各里彙總
實測：五人排名與三人排名的領先結果 **0 筆不同**），故成圖與五人版完全相同。

```python
CAND_NAMES = ["連戰", "陳水扁", "宋楚瑜"]     # 順序＝ RATE_COLOR_STOPS 順序
CAND_RATE_COLS = [f"{n}得票率" for n in CAND_NAMES]
```

### 2.2 配色（由使用者指定，**不沿用** `County/1996President.py` 或 `County/2000President.py`）

| 組 | 候選人 | 政黨 | 色階（35% 起，5% 一階） |
|---|---|---|---|
| 1 | 連戰 | 中國國民黨 | 藍 `#B0E3F0 → #000814`（35~100%，**12 階**） |
| 2 | 陳水扁 | 民主進步黨 | 綠 `#E8FFE0 → #071A09` |
| 3 | 宋楚瑜 | 無黨籍（親民黨） | 灰 `#D9D9D9 → #151515`（35~85%，**11 階**） |

> 注意：宋楚瑜組使用者僅給到 85%（`#151515`）。`nat.get_color_by_value` 對 >85% 的值
> 會回傳最後一階（同色），故不需另補 `(100, …)` 階。
>
> **2026-10-09 修訂**：
> - ① 宋楚瑜色階由原 `#FFFFFF → #646464` 改為 `#D9D9D9 → #151515`
>   （35% 起即為淺灰，不再與「無資料留白」純白同色）。
> - ② 連戰色階由原 `#D9F6FF → #010D29` 改為 `#B0E3F0 → #000814`（12 階，含 100% 端點）。
>
> 兩次修訂皆七檔（六支腳本＋`_gen_2000.py`）同步更新；陳水扁綠階未動。

### 2.3 資料路徑與得票「數」欄位選取

- `VOTE_XLSX` / `VOTE_DETAIL_XLSX` → `2000總統副總統選舉_*.xlsx`。
- **`Draw_North4_President_2000.py` 的明細得票數欄位**：2000 明細表有 **5** 組
  `XXX（NN）_得票數` 欄，1996 版「取全部 `_得票數` 欄」的寫法會因欄數不符而全部跳過，
  故改為**依 `CAND_NAMES` 逐一挑選**：

  ```python
  cnt_cols = [next(c for c in dc.columns
                   if c.endswith("_得票數") and c.startswith(n))
              for n in CAND_NAMES]
  ```

### 2.4 年份標示全量替換

`1996` → `2000`、`第九屆` → `第十屆`、輸出檔名／報告標題／`layer_name`／
識別字（`VARIANT_CHAR_MAP_2000`、`TOWN_VILL_RENAME_2000`、`rename_town_vill_2000`…）
一併更名；檔名 `_1996.py` → `_2000.py`。

### 2.5 村名修補表的唯一調整：移除新竹「偉功 → 武功」

| 項目 | 1996 | 2000 |
|---|---|---|
| 新竹市東區村里 | 只有「偉功里」（50 里），2012 圖資作「武功里」 | **「偉功里」與「武功里」並存**（53 里，兩筆得票數各自獨立） |
| 1996 版處理 | `VOTE_NAME_REPAIR` 把 偉功 → 武功（視為誤植） | **不設此條** |

2000 資料兩里並存，若沿用該修正會把兩筆併為一筆而**靜默丟失資料**；
故 2000 版移除，讓「偉功里」如實列為反向缺漏（報告第 3 節），供人工核對。
2012 圖資只有「武功里」，故此差異**不影響地圖畫面**，僅影響稽核報告。

其餘修補表（PUA 碼位、「■」佔位符、`VOTE_NAME_REPAIR` 苗栗公館「石墻」、
`TOWN_VILL_RENAME_2000` 高雄那瑪夏 3 村＋桃源拉芙蘭、`SHP_NAME_REPAIR` 北屯廓子→部子、
`CITY_VILL_REPAIR` 嘉義磚嗂→磚窯）**全部原樣沿用**，2000 資料實測依然成立。

### 3.1 2000 與 1996 資料集差異造成的稽核報告變動

兩年份村里集合不同（全國交集 7490；1996 獨有 15 筆、2000 獨有 203 筆），
下列為 **2000 版新出現**的留白／反向缺漏，皆為**資料集本身**的差異，
已逐筆列於各區報告，未做任何推測性改名：

| 區域 | 類型 | 新出現者 | 成因 |
|---|---|---|---|
| 桃竹苗 | 反向缺漏 +1 | 新竹市東區 偉功 | 2000 資料偉功/武功並存，2012 圖資僅有武功（§2.5） |
| 雲嘉南 | 留白 +2 | 嘉義市西區 翠岱里、致遠里 | pre2010 圖資有此二里，2000 得票資料已無 |
| 雲嘉南 | 反向缺漏 +3 | 臺南市北區 城隍、福德、花園 | 2000 資料有、2012 圖資無 |
| 高屏 | 留白 +1 | 屏東市 崇智里 | 1996 資料作「崇智里」、2000 作「崇禮里」；2012 圖資**兩者皆有**，故崇禮里已精確匹配、崇智里留白 |
| 中彰投／臺中舊市區 | 留白 +4 | 臺中市北區 光榮里、平等里；南區 中南里；西屯區 鵬程里 | 民國85年 SHP 有此四里，2000 得票資料未單獨列 |

> 其餘留白／反向缺漏與 1996 版成因相同（臺南中/西區 2004 合併、嘉義市里重編、
> 宜蘭羅東鎮 1996 村里重編等），詳見 `1996Precident/scripts/README.md` §12.2。
