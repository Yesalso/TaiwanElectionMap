# 2022 九合一縣市長看板 —— 使用說明

> 22 縣市 × 縣市長選舉看板，每縣市一張 **3840×2160（4K）** 的開票看板。
> 專案根目錄：`Mayors/2022NineInOne/board/`

---

## 一、成果

- **22 張看板，全部放在同一個年份資料夾**：`dist/dist_png/2022/<縣市>.png`
  （檔名即縣市全稱：`臺北市.png`、`新北市.png` … `連江縣.png`，22 張同一層）
- 同一層還有一張 **全國看板（政黨版圖）** `dist/dist_png/2022/全國.png`
  （3840×2160，兩張全國地圖並排＋六家政黨席次與得票）—— 見 §九。
- 每張看板含：
  - 頁眉：國旗 → 標題「2022年九合一選舉」 → 年份圓盤 2022＋日期 → 縣徽白卡 → 四行數據（投票率/有效票/無效票/選舉人數） → **時任縣市長**（選舉當下在位者）
  - 左/右主卡：得票前兩名（政黨色卡＋黨徽＋姓名＋得票率＋票數）
  - 中：村里級得票地圖（主圖）
  - 右欄／下方：鄉鎮級得票地圖（map2，依地圖形狀左右或上下放置）
  - 底部：第 3 名起的小卡帶＋得票比例帶

## 三、重跑命令（PowerShell / Git Bash）

```bash
PY="C:/Users/Windows/AppData/Local/Programs/Python/Python313/python.exe"
NODE="C:/Users/Windows/.workbuddy/binaries/node/versions/22.22.2-6/node.exe"
cd Mayors/2022NineInOne/board

# ① 素材去背（地圖＋縣徽）＋背景照分組複製
PYTHONIOENCODING=utf-8 $PY src/tools/build_assets.py
#    只補背景照、不動地圖/縣徽：$PY src/tools/build_assets.py --bg

# ② 建置看板資料
PYTHONIOENCODING=utf-8 $PY src/tools/_gen_boards.py

# ③ 渲染 22 張（預設 1.5×＝3840×2160，落 dist_png/2022/<縣市>.png）
$NODE src/tools/render_boards.mjs --all

# ④ 版面驗證（期望：22 份報告，0 份未通過）
$PY src/tools/verify_layout.py

# ⑤（只在黨徽原圖更新時）重製政黨徽章，再重渲染用到該黨的場次
$PY src/tools/build_party_marks.py tpp        # 只做指定黨；不帶參數＝只補缺的
$NODE src/tools/render_boards.mjs --boards 2022-hsinchucity
```

只重跑單一縣市（例如臺北市）：

```bash
PYTHONIOENCODING=utf-8 $PY src/tools/build_assets.py 臺北市
PYTHONIOENCODING=utf-8 $PY src/tools/_gen_boards.py 臺北市
$NODE src/tools/render_boards.mjs --boards 2022-taipei
```

> **★ 不要用 `WindowsApps\python.exe`（會往專案裡裝一整份 Python）**
> 那個路徑是「Python 安裝管理器」的轉接器（pymanager stub）。它會依**當前目錄**找／建安裝，
> 找不到就直接下載安裝一份 Python 3.15（`./Python/pythoncore-3.15-64`，約 300MB、3000+ 個檔）。
> 2026-10-28 專案裡冒出來的 `Mayors/2022NineInOne/Python/`（以及倉庫根的 `TaiwanElection/Python/`）
> 就是這樣產生的，已經整份移到資源回收桶清掉。**腳本一行都不引用它**，不必也不能靠它跑。
>
> 現在統一用系統的 Python 3.13（依賴已裝好，版本與原 `Python/` 內一致）：
>
> | 套件 | 版本 |
> |---|---|
> | numpy | 2.5.4 |
> | pandas | 3.1.0 |
> | pillow | 13.0.0 |
> | openpyxl | 3.1.5 |
>
> 換機器／重裝時補一行即可：
> `C:/Users/Windows/AppData/Local/Programs/Python/Python313/python.exe -m pip install numpy pillow pandas openpyxl`
>
> 三支 Python 腳本都用 `__file__` 定位專案根，所以在 `board/` 或上一層跑都可以。
> 若 `which python` 指到 WindowsApps 的 stub，**先確認自己不是在專案目錄裡執行它**，否則又會長出一份 `Python/`。
> `node` 那幾行不受影響（`render_boards.mjs` 也用 `__dirname` 定位）。

- `--scale` 不加＝**1.5**（2560×1440 版面 ×1.5 ＝ **3840×2160**，即交付尺寸）。
- `--scale 1` ＝ 2560×1440；`--scales 1.5,2` 出多份，首個倍率不帶後綴、其餘加 `_2x`（`臺北市_2x.png`）。

## 五、版面設計要點

### 頁眉（沿用總統看板風格）
從左到右：**國旗白卡 → 標題「2022年九合一選舉」→ 年份圓盤 2022＋日期 → 縣徽白卡 → 四行數據（投票率/有效票/無效票/選舉人數）→ 時任縣市長（色卡＋姓名＋政黨）**。

- 頁眉右側色卡畫的是**選舉當下在位者**（時任縣市長），不是當選人；當選人已在左右主卡與底部小卡帶上，不重複。
- 資料來自簡報 md「四、各县市结果总表」的『時任首長（黨籍）』欄，`_gen_boards.py` 的 `parse_brief_incumbents()` 解析（簡→繁、政黨全稱對照、`（无党籍，代理）`→角色標籤加「（代理）」，如新竹市陳章賢）。
- 角色標籤 `meta.header.role` 固定為「時任縣市長」，代理者為「時任縣市長（代理）」。
- **個案修正**：臺北市柯文哲記為**台灣民眾黨**（2019 年創黨並任主席，2022 投票當下為民眾黨籍；簡報照中選會「無黨籍及未經政黨推薦」欄記為無黨籍）。實作在 `county_map.INCUMBENT_PARTY_OVERRIDE`，目前只列臺北市一場，其餘 21 縣市照簡報原文。

### 兩張地圖的擺位（2026-10-28 改：比例不再定死，由寬高比算）
舊版是兩套固定框（直圖 `w880`＋右欄 `564×700`；橫圖 `1430×470`＋`1430×390`），框和圖對不上，contain 後左右留一大片白：臺中框 1430×470 只畫到 968×470，苗栗只用到 43% 寬。現在改成 `_gen_boards.plan_maps()` 依每縣市兩張圖的**實際寬高比**算出「框＝圖」再擺位：

- 可用區 `x 560..2004`、`y 196..1092`（右主卡 2024、小卡帶 1102）；左右並排時村里圖可長到 `y1230`（沿用舊版高度），鄉鎮圖一律留在 `236..1092`（頁眉下、小卡上）。
- 兩種擺法（上下、左右）各做一次一維搜索，取**兩張面積和最大**且滿足約束的一組：
  - 村里圖面積 ≥ 鄉鎮圖 × **1.35**（主圖必須明顯大，`VILLAGE_AREA_MIN`）；
  - 鄉鎮圖長邊 ≥ 村里圖長邊 × **0.40**、短邊 ≥ **200px**（不能縮成小貼紙）。
- 結果：22 場兩張圖的總面積 **19.9M → 22.2M px（+12%）**，村里圖普遍放大 1.5–3 倍（苗栗 609×470 → 1001×772），鄉鎮圖縮到 0.4–0.6 倍並靠邊對齊。
- 兩個實測例外（L9 定出來的，改版面要重跑驗證）：`MAP_BAND_INSET = {"臺北市": 85}`（村圖下探段只剩文山一帶，整組右移 85px 閃開左側 others 卡）、`MAP_TALL_OFF = {"彰化縣"}`（下探段幾乎橫貫全圖，只能把村圖壓回 1092）。
- 逐場覆寫在 meta.layout（`LAYOUT_OVERRIDABLE = ['legend','map2','map']`）；`_gen_boards` 會把算好的 x/y/w/h 寫進去。

### 主卡姓名自適應
- 超長名（花蓮「谷辣斯．尤達卡 Kolas Yotaka」）先去掉英文羅馬拼音（`clean_name`），只留中文。
- 仍超長時**縮字號**完整顯示（不截斷，下限 0.4 倍，**字距隨字號等比縮**），仍超才 fitText 兜底。
- `maxNameW = 492`（右主卡姓名左緣不壓 map2 框右緣 2004）。

### 第 3 名高卡超長名換行
- 嘉義市黃宏成（15 字）在 `county_map.NAME_WRAP` 設顯式斷點，拆成兩行「黃宏成台灣阿成／世界偉人財神總統」。
- 引擎 `wrapName()` 只按 `\n` 斷行，`drawBig` 逐行畫、`bigStackHeight`／`bigScale` 把姓名行數算進堆疊高與字級。
- 順帶修正 `capFactor` 過度縮字 bug：原用「還原自然寬」且 caller 再 `fit * cap`，超長名會被連乘縮到 0.33；改為「當前寬度」一步收斂（黃宏成現在 scale≈0.725，字級 36px，完整兩行不截斷）。

### 低得票率候選人的圖片框改用占位圖（2026-10-28）
- 規則：**得票排名 ≥ 3 且得票率 < 3%** 的候選人，圖片框一律改畫 `assets/low_pct.png`（灰階人形剪影），不再留政黨純色塊、後製也不必補照片。
- 判斷式只有一處：`engine/js/model/election-model.js` 的 `Candidate#usesLowPctPhoto()`（常數 `LOW_PCT_RANK = 3`、`LOW_PCT_LIMIT = 3`）；`rank` 由 `ElectionModel` 依總票數排出（1 起算，跨全部候選人），與主卡／小卡帶怎麼分槽無關。
- 繪製：`layers.js` 的 `minorBlock()` 收到 photo 就 cover 滿框＋圓角裁切，第三名高卡（`drawBig`）與小卡（`drawSmall`）共用；沒傳或讀不到圖才退回政黨純色，圓角亮線兩種情況都照畫（後製對位線不變）。
- 素材：`build_assets.py` 的 `build_photo_fallback()` 原樣複製（不去背、不縮放，任何比例都吃得下）→ `dist/assets/share/low_pct.png`；`_gen_boards.py` 把它登記成 `low_pct.png` 寫進每場 `board.files.js`。**素材沒登記時引擎會安靜跳過**（退回純色塊），所以改了素材記得重跑②。
- 命中範圍：16 縣市共 **37 人**（第三名高卡 8 人：彰化蕭仁正、嘉義市黃宏成、新竹縣范振揆、高雄曾尹儷、南投王永慶、臺中陳美妃、臺東陳長宏、雲林林佳瑜；其餘為小卡），臺北市一場就 9 人（第 4–12 名全在 0.2% 以下）。

### 背景照（按區域分三張，2026-10-28 起）
原本 22 縣市共用一張 `街景2.png`；現按區域換成三張，`county_map.BG_GROUPS` 是唯一真值表：

| key | 原圖 | 縣市 |
|---|---|---|
| `north` | `街景1.png`（中正紀念堂空拍，白天） | 臺北市、新北市、基隆市、宜蘭縣、桃園市（5） |
| `hsinchu` | `新竹.png`（新竹迎曦門夜景） | 新竹縣、新竹市、苗栗縣、臺中市、彰化縣、南投縣、雲林縣、嘉義縣、嘉義市、臺南市（10） |
| `kaohsiung` | `高雄.png`（高雄港夜景） | 高雄市、屏東縣、花蓮縣、臺東縣、澎湖縣、金門縣、連江縣（7） |

- 同組共用一張 → `dist/assets/bg/<key>.png` 只存 3 個檔（省下約 100MB 重複）；`_gen_boards` 逐場把邏輯名 `street_bg.png` 指到對應檔。
- 原樣複製、不做透明化；繪製時 cover 鋪滿＋`dim 0.50` 暗色遮罩＋底色漸層再壓 45%，所以 16:9、4:3、3:2 的原圖都能用，不會拉伸。

### 政黨徽章（192×192 圓徽）
- 引擎把黨徽當**內切於正方形的圓**畫在深藍底上（`layers.js`：`drawImage(img, sx, markY, markW, markW)`），所以成品必須「圓內不透明、圓外 alpha=0」，否則深藍底上會多出一個色塊。
- 原圖三種形態要分開處理（`build_party_marks.py` 的 `MARKS` 表，`auto` 會依「邊框是否透明／是否純白」自動判斷）：
  - `keywhite`（PFP/NSC/IND，白底＋彩色圓形主體）→ 白底轉透明 → 裁 alpha 外框 → 等比縮進 192²。
  - `alpha`（DPP 新版，935²、圓外已透明、**圓內是白底**）→ 只裁 alpha 外框 → 縮進 192²。**切勿去白**：白底是徽章本體，去白後只剩綠十字＋台灣地圖浮在深藍底上。
  - `circle`（TPP／KMT 新版）→ 底色即徽章本體、不能去背 → 置中裁正方形 → **內切圓遮罩**（4× 超採樣抗鋸齒）→ 192²。
    - TPP：蒂芬妮綠方底＋奶油色「眾」→ 綠圓＋白字。
    - **KMT（2026-10-28 換版）**：1280² 不透明方框、藍圓盤內切、盤心是**純白白日＋12 道光芒**。這張走 `keywhite` 會把白日一起挖掉（實測圓心 75.7% 變透明，深藍底上只剩一個藍圈），只能走 `circle`：只切掉四個白角，白日原樣保留（圓心 alpha 全 255、整體透明 20.6%）。
  - `MARKS` 的形態是**逐檔指定**的（`kmt` 這條就是從 `keywhite` 改成 `circle`），換素材時先看新圖是「白底＋圓主體」還是「方底＋內切圓」，別直接沿用舊形態。
- 只有「得票前兩名」的主卡會畫徽章；第 3 名起的高卡仍是政黨純色塊。所以換 TPP 徽章只影響新竹市（高虹安），桃園／宜蘭的 TPP 是第 3 名、走色塊；DPP 則幾乎全台都是前兩名，21 場要重渲染（金門無 DPP 候選人）。KMT 同理：國民黨在 21 場是前兩名，換版後 21 場都要重渲染（連江縣由 KMT 拿下、也在其中）。

### 沒有黨徽的小黨：`PARTY_COLOR` ＋ `candidates[].color`（2026-10-29）
- 不是每個政黨都該有自己的徽章素材。**時代力量**（2022 基隆市陳薇仲）就沒有，所以**不進** `build_party_marks.MARKS`、也不進 `slide.js` 的 `PARTIES_WITH_MARK` —— 主卡位置會自動退回純色塊（`Marks.partyChip`），不會去抓「無黨籍」那枚圓標。
- 顏色走「資料層宣告、引擎推導」：`county_map.PARTY_COLOR` 登記 `時代力量 → #FFBE00`，`_gen_boards.py` 只對**有登記的政黨**寫 `candidates[].color`；引擎的 `Candidate` 看到 `color` 就走 `Theme.fromColor()` 算出 light／dark／accent／map 五階。沒登記的候選人**不寫這個欄位**，`board.js` 與原本逐位元組相同，其他場次不受影響。
- `Candidate.partyKeyOf()` 多一條 `NPP → 'npp'`：若沿用 `ind`，主卡徽章會誤抓無黨籍圓標，地圖色階也會變灰。`Theme.party('npp')` 找不到時退回 ind 灰，但這位有 `color`，實際走 `fromColor`。
- 目前的範圍：**三場**——基隆市（陳薇仲 12,000 票 6.56%）、苗栗縣（宋國鼎 39,347 票 13.47%）、屏東縣（詹智鈞 19,156 票 4.32%）。三人的卡片與底部得票比例帶都是 `#FFBE00`，標籤顯示「時代力量」，且都不會出現黨徽。

## 八、項目經驗總結

### 1. 架構決策

- **複製引擎 + 獨立專案目錄**：`render_boards.mjs` 用 `resolve(__dirname, '..', '..')` 定位專案根，放在 `board/src/tools/` 後自動指向 `board/`，渲染器**零改動**。
- **四份數據源合一**：xlsx（候選人得票）+ Wikipedia.txt（投票率等）+ `county_map.CAND_PARTY`（黨籍）+ 簡報 md（時任首長），全部在建置器 `_gen_boards.py` 聚合；頁眉要換人只需改簡報那張表，不必動程式。
- **單一真相源** `county_map.py`：22 縣市的繁簡對照、徽章對應、資料檔對應、黨籍、地圖墨跡比全集中一處，建置器與去背器共用。

### 2. 版式迭代教訓

- **不要輕易推翻成熟版式**：初版改成「大字標題」頁眉，用戶要的是「在總統看板框架上做增量」（保留國旗＋年份圓盤），最終回到原風格。先問清楚「保留哪些、改哪些」再動手。

### 9.5 素材處理（這一節是重點）

來源兩張都是「全台單張、不透明平面底色」的成品圖（3955×5033），四道處理：

1. **底色轉透明**：縣市級底色 `(120,120,120)`、鄉鎮級 `#323232 (50,50,50)`，
   用「三通道差都 ≤ 8」判底色，抗鋸齒暈邊一起帶走。
   **但資料填色要先保護起來** —— `color.txt` 裡的每一階都算「這是資料」，
   再接近底色也不挖（`_fill_color_mask`）。因為鄉鎮圖底色 `#323232` 與
   無黨籍 75% 的 `#333333` **只差 1**，照「差 ≤ 8」會被整塊挖成透明（苗栗縣踩到）。
2. **挖掉左上角大陸輪廓**：`CHINA_BOX = (0,0,1400,918)` 整區 alpha 歸零。
   **不能用「裁掉上面幾列」** —— 台灣最北端（y≈485）比大陸輪廓下緣（y≈918）還高，
   橫向裁切會先切掉台灣。
3. **黑界線轉白並加粗**：來源的縣市界／鄉鎮界是純黑 3–5px（繪圖腳本用純黑堤壩再洪水填色），
   深色底上看不見，而且成品縮到 640px 寬（縮 4.3 倍）細線會消失 →
   `max(R,G,B) ≤ 12` 轉白 + 3×3 最大值濾波一次（線寬 +2px）。
4. **兩張圖共用同一個裁切框**：墨跡外框取兩者**聯集**（x353..3121、y477..4171），
   各裁 2769×3695 → 擺在一起時比例、位置、三個放大框全部對齊。

> 裁切框的求法：先算「整列／整行墨跡像素 > 40」的範圍（避免右上角零星小島點把畫布拉回整張圖），
> **再往外 pad 8px**。寫成往內縮會切掉台灣最北與最南端（第一版踩過）。

5. **資料填色保護**（2026-10-29）：`national_map.all_ramp_colors()` 讀出 `color.txt`
   **所有組**的階色，`build_national_assets._fill_color_mask()` 把它們標成「一定是前景」。
   這一步讓苗栗縣那塊 `#333333`（無黨籍 75%）不再被當成底色挖掉。
6. 判斷式是 `fg = ~close | fill`（＝「不像底色」**或**「是合法填色」），
   只會讓更多像素變成不透明、不會反向吃掉背景 —— 所以修完地圖的裁切框、
   版面尺寸都沒有變（仍是 x353..3121／y477..4171，2769×3695）。

### 9.8 已知限制 / 可選優化

- 兩張地圖是**高度受限**（854px），島身寬約 430px。要更大只能：關掉底部小卡帶
  （`minors` 現在已可逐場覆寫，但仍受 560..1990 這條帶的寬度限制）或改主卡寬度
  （`Layout.left/right` 仍不可覆寫）。
- 來源圖自帶三個放大框（金門／馬祖／澎湖），保留原樣；它們佔掉每張圖左側約 27% 寬度，
  換來的是離島可辨。**拿掉底板之後，這三個框只剩細邊線、框內是透明的**（照片透出來），
  在畫面上比較像「浮著的空框」。若嫌雜，兩條路可選：
  1. 只留本島 → `national_map.CHINA_BOX` 之外再把裁切框改成 `x≈1450..3121`；
  2. 只給三個放大框鋪一層暗底（`build_national_assets.py` 加一個「框內填色」步驟），其餘仍透明。
- **底部比例帶已關閉**（`meta.layout.ribbon.disabled`）。原本六段佔比在 2560 寬下
  其他政黨只有 6px（`RibbonLayer` 的下限）；關掉後這 6 家改由清單格逐列呈現，資訊反而完整。
- 清單格的字級（約 22px）比小卡（27px）小一截 —— 是寬度受限下的自動縮字（見 9.7 #18）。
  第五版把席次條空出的寬度讓給它（`othersMaxTextW` 300 → 338）；再往上就會頂到 L8 的
  左界 560，要放大只能先縮高卡的文字欄或減少列數。
- 圖例最右幾階（國民黨 `#001F2E`、民進黨 `#0F210A`、民眾黨 `#000808`）近乎純黑，
  在深色底上幾乎看不出來 —— 這是 color.txt 本身的階色，地圖上最深那批鄉鎮也是同一組色。
