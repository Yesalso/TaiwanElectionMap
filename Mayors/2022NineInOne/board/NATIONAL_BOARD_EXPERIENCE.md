# 全国看板开发经验（2022 县市长选举 · 政党版图）

> 一份把「全国看板」这轮开发踩过的坑、定下的做法，从 `README.md §9` 里单独抽出来沉淀的经验文档。
> 目标是：以后再做「全国／政党版图」这类看板，照着这份走，不再重踩一遍。
> 对应代码与数据：`board/src/tools/{national_map,build_national_assets,_gen_national}.py`、
> `board/src/engine/js/{core/theme.js,core/layout.js,model/election-model.js,render/layers.js}`。

---

## 一、这一场要解决的核心问题

把两张「全台单张、不透明平面底色」的成品地图，做成**一张**看板：

| 输入 | 是什么 |
|---|---|
| `map/2022县市.png` | 县市级的当选政党（各政党平涂色） |
| `map/2022縣市長選舉_鄉鎮市區得票率.png` | 乡镇市区的得票率（颜色＝政党，深浅＝得票率） |
| `2022县市长选举简报.md` | 唯一数据源（总体结果／政党总得票／席次分布三张表） |

而这一场的「候选人」是**政党**，不是人——这决定了几乎所有差异点。

---

## 二、总体思路：复用引擎，只做 opt-in 扩展

**红线：现有 22 场县市长看板输出，逐字节不能变。** 每一轮改完都实测量：重渲染臺北市，PNG 的 sha256 前后必须相同（`72c1bfb429a22d86…`）。

所有新能力都做成 **opt-in 字段**——只有 `meta.json` / `board.js` 里**声明了**才走新分支，没声明就完全走旧路径：

| 字段 | 作用 |
|---|---|
| `candidates[].seats` | 主卡姓名旁一块席次牌 ＋ 小卡照片下的席次条 |
| `candidates[].leader` | 主卡大字改印党主席（党名留在 chip） |
| `candidates[].sub` | 小卡副行改字；`''` = 副行留白 |
| `meta.header.stats` | 页眉四行数据自订标签／值 |
| `meta.header.photo === false` | 不画「时任首长」色卡 |
| `meta.figures === 'display'` | 阿拉伯数字改用日期块那支字型 |
| `layout.minors` | 逐场覆写小卡带（`smallMax`／`groupGap`／`subInk`／`othersMaxTextW`） |
| `layout.map2.allowWithLegend` | 图例开着时仍画第二张图 |
| `layout.legend.allowInHeader` | 图例摆在页眉带内 |

**新增脚本 3 个**，渲染逻辑一行没重写：
- `national_map.py` —— 全国场唯一真值表（路径、去底参数、色阶、政党简繁对照、版面常数）
- `build_national_assets.py` —— 素材管线（去底→挖大陆→黑线转白→共裁切框→图例）
- `_gen_national.py` —— 只读简报 md，生成 board.js

## 三、素材处理：四个坑 + 一个隐藏大坑

来源图是「绘图脚本先画黑堤坝、再洪水填色」的成品，去底时必须按它的脾气来。

1. **底色转透明**：县市图底 `(120,120,120)`、乡镇图底 `#323232`，用「三通道差 ≤ 8」判底色，抗锯齿晕边一起带走。
2. **挖掉左上角大陆轮廓**：`CHINA_BOX=(0,0,1400,918)` 整区 alpha 归零。**不能用裁切**——台湾最北端（y≈485）比大陆轮廓下缘（y≈918）还高，横切会先切掉台湾。
3. **黑界线转白并加粗**：来源界线是纯黑 3–5px，缩到 640px 宽（4.3 倍）细线会消失 → `max(R,G,B)≤12` 转白 + 3×3 最大值滤波（+2px）。
4. **两图共用同一裁切框**：墨迹外框取联集，否则两图高度差几 px、放大框对不齐。
5. **（第九轮才发现）资料填色会被当成底色吃掉**：
   - 乡镇图底色 `#323232`，无党籍 75% 那一阶是 `#333333`，**只差 1**。
   - 照「差 ≤ 8 即底色」→ 苗栗县一块深灰乡镇被挖透明，透出街景照片。
   - **正解**：去底前把 `color.txt` 里**所有组**的阶色列成「合法填色白名单」（`all_ramp_colors()`），
     `fg = ~close | fill`（「不像底色 **或** 是合法填色」）。这只会多保留像素、不会反向吃掉背景，所以裁切框和版面不变。

> 教训：**「与底色差多少」是不可靠的去底判据**。当填色范围与底色重叠（灰度图尤其如此），必须先保护数据色。

裁切框求法：算「整列/整行墨迹像素 > 40」的范围（别让右上角小岛点把画布拉回整张图），**再往外 pad 8px**（往内缩会切掉南北端）。

## 四、版面：政党当「候选人」带来的差异

- **主卡**＝照片位（452×620，**一律不放数字**）＋ `[徽章] 党名`（chip）＋ `[席次牌] 党主席`＋得票率＋票数。党主席名单在 `national_map.PARTY_LEADER`（朱立伦／蔡英文／柯文哲／陈椒华）；无党籍、其他政党没单一负责人 → 不列。
- **小卡**沿用台北市那套（照片位 + 党名/主席/得票率/票数），**席次条放在照片下方**，不压照片。
- **政党太多 → 走台北市的「其他候选人清单」**：`layout.minors.smallMax` 指定最多几张窄卡，其余进清单格（`- 名称 票数`）。
- **「其他政党」逐党列出**：数据全部来自简报 **§2.4「看板采用口径」表**（11 行，逐党列名＋票数），
  小党各占清单一行。那张表是刻意与 §2.1／§2.2 不同的口径（大党沿用广义口径、其余按登记党籍），
  并替代了早期「解析注脚 ‡、再把 5,883 票摊回 6 家」的做法。
- **图例**：色阶直接读 `color.txt`（四家：国民党/民进党/民众党/无党籍，各 12/12/12/11 阶），顶部加一条比例尺（`LEGEND_TICK_STEP=2` → 每 10 个百分点标一次 35/45/55…）。
- **底部得票比例带关掉**：小卡带已讲完席次/得票率/票数，比例带只是重复。

## 五、席次牌的演化（这是被反复改得最多的部分）

需求一路在变，最终形态是「**独立牌匾 / 席次条 + 纯数字**」：

| 迭代 | 需求 | 结果 |
|---|---|---|
| v1 | 席次画进色卡中央 | 压到照片位，被否 |
| v2 | 席次牌独立、带 ✓ | 数字显小 |
| v3 | 去掉 ✓、放大数字 | 最终形态 |
| v4 | 席次条移出照片、直角无边框、去「席」字 | 最终形态 |

关键做法（最终版）：
- 主卡牌匾：`pH = 0.86×姓名字级`、`pW = 1.34×pH`、`numSize = 1.05×pH`，`fillRect` 直角、无描边、`cjk:false`（不印「席」）。
- 小卡席次条：`条高 = 方块高 × 0.28`、`numSize = 1.16×条高`，基线下移 0.36em 才真正居中。
- **牌匾尺寸必须在 `layers.js` 和 `headless.js` 两处同步**，否则量测失真（L3/L6 会用错矩形）。
- 席次条的比例常数抽成 `SEAT_BAR = { hRatio, gapRatio, minH }`，`minorBlock` 和 `seatPhotoW` 共用——原来各写一份，改一个忘另一个。

## 六、字体：只换数字、不动中文

需求是「阿拉伯数字都用『2022』那支字型」（`Noto Sans UI Black`）。

**一行主题级开关，不碰任何绘制点**：`theme.js` 在定义 `FONT_NUM` / `FONT_DISPLAY_NUM` **之前**判断
`BOARD.meta.figures === 'display'`，把 `"Noto Sans UI Black"` 排到 `FONT_STACK` 最前面。

- 它只有西文字身 → 数字/英文走它，中文逐字掉回源石黑体，等于「只换数字、中文不动」。
- 用 `indexOf` 防重复叠层。
- 其他场次没这个字段 → 字型堆叠一字不改。

## 七、验证纪律（每一轮都做）

1. `verify_layout.py`：23 份报告 0 未通过。
2. **回归**：重渲染臺北市（有时加苗栗、高雄），sha256 与改动前逐字节相同。
3. 全链路重跑 sha 稳定（同一输入必须产出同一 PNG）。
4. 每轮都清理 `manifest.json` 里「1× 调版面临时记录」，只留交付尺寸（3840×2160）。
