爬取政大网页生成表格获取数据

════════════════════════════════════════════════════════
爬取经验总结（vote.nccu.edu.tw 中央选举委员会选举数据库）
════════════════════════════════════════════════════════

1. 入口网址
   vote3.asp?pass1=<token> 为全国入口，token 随选举不同：
   1996=I9AA>I...、2000=I:888I...、2008=I:88@I...、2012=I:89:I...
   抓入口页即可拿到候选人清单、得票数与下钻链接。

2. 页面层级（下钻链）
   vote3   全国（10 栏含 rowspan，总统/副总统同号次，取总统列）
   → vote312 现市（25~26 现市）
   → vote313 乡镇市区（约 368 个）
   → vote32  村里（约 7800 行/候选人，叶子层无链接）
   旧选举（如 1997 台北县长）走 vote31 直入乡镇，固定下钻 vote32。

3. 编码
   页面为 big5，必须手动 r.encoding = "big5"，否则中文全乱。
   输出文件用 UTF-8（openpyxl 默认）；PowerShell 控制台显示乱码不影响文件。

4. 解析要点
   - 用 tr.find_all("td", recursive=False) 只取直属单元格，
     rowspan 行才能拿到完整的 10 栏（地区/姓名/号次/性别/出生年/政党/得票数/得票率/当选否/是否现任）。
   - 候选人去重：正副总统同号次，VP 行只有 4 栏，按号次 seen-set 过滤。
   - 5 栏层级页（地区/姓名/号次/得票数/得票率）：跳过表头，
     校验 vals[3].isdigit()，姓名栏有 <a> 才能继续下钻。
   - 地区栏是「上层+本层」相连字串（如 臺南縣學甲鎮仁得里），
     用 area[len(prefix):] 切出本层名称，切之前先 startswith 检查。
   - 下钻链接是相对路径，需拼 BASE_URL；链接含候选人的 pass1 token（每候选人一份）。

5. 稳定性
   - 伪装浏览器 User-Agent；失败重试 3 次并退避。
   - 页面间 delay（0.2~0.3 秒）限速，避免压垮旧 ASP 站。
   - 磁碟快取：sha1(url) → html 文件，中断重跑直接续抓（关键，全量约 790 页）。
   - 乡镇/村里层用 ThreadPoolExecutor（5~6 worker）并行；入口与现市层串行即可。
   - 注意：后台启动的进程可能被环境回收，长时间任务用前台 + python -u 看进度。

6. 输出与校验
   - openpyxl 交叉表：每位候选人两栏（得票数/得票率）+ 冻结首行 + 边框样式。
   - 三层各自加总，与全国公告票数核对，打印差额。
   - 已知源站缺口（已补正）：2008 臺南縣學甲鎮村里页只列 12 里，
     少「大灣里」（马英九281票/36.12%、谢长廷497票/63.88%）。
     已手动补入，补完后 25 县市、368 乡镇、7788 村里三层全数核对一致。

7. 脚本分工
   GetData.py            通用多层入口（vote3/312/313/31/32 自动识别，串行无快取）
scrape_president_2008.py  2008 专用（快取+并行+三层交叉表）
    scrape_president_2004.py  2004 专用（快取+并行+三层交叉表+投票所明细）
    scrape_president_2012.py  2012 专用（另输出得票率专用档）
    scrape_president_2000.py  2000 专用（快取+并行+三层交叉表+全国总数验算）
    scrape_president_1996.py  1996 专用（快取+并行+三层交叉表+全国总数验算）
    scrape_president_1996_flat.py  1996 平表（10 栏，含 VP 行续接，旧版改名保留）
    scrape_president_1996_levels.py  1996 两层级（县市+乡镇），已被 1996 三层版取代
