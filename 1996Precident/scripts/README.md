## 2. 改造一：底图图源 SHP → JSON

参考 `Base_JSON/draw_json_map.py`、`draw_county_maps.py`、`drawcore.py` 绘制 `.json` 的做法，
用 JSON 取代原本的 `VILLAGE_MOI_1081121.shp`。

### 2.1 做法（新增 `load_base_map()`）

```
gpd.read_file(json)
  → 栏位 county/town/village（小写）正規化为 COUNTYNAME/TOWNNAME/VILLNAME
  → gdf.crs is None → 补 EPSG:4326
  → to_crs(EPSG:3826)
  → 筛 TARGET_COUNTIES 四县市、buffer(0)、去 nan/空值
```

关键点：**只换图源，不动下游**。JSON 的栏位改名成与 SHP 版同名后，
`dissolve` / 匹配 / `strip_far_parts` / `remove_ring_slits` / 填色 / 自检全部原样复用。

### 2.2 SHP 与 JSON 的差异（会影响画面，非 bug）

| 项目 | 108 版 SHP | twvillage2012.json |
|---|---|---|
| 北北基宜图斑 | 含龟山岛、基隆屿等离岛 | **单一连通块、无 >500m 离岸图斑** |
| 「头城镇龟山里」 | 龟山岛 | 本岛沿海村里（不含龟山岛） |
| 「无村里名」图斑 | 有（基隆外海礁岩等） | 0 笔 |
| `strip_far_parts` | 剔除离岛 | 不剔除，`n_islands=0` |
| ② 層连通分量 | = 本岛 + 保留离岛 | `EXPECT_CC=1` |

→ **这一版不会画出龟山岛 / 基隆屿**。`EXPECT_CC` 由数据动态算出，自检自洽，不会误报。

## 4. 改造三：村里沿革合并（四县市：台北／新北／基隆／宜兰）

参考 `MayoralElections/scripts/20/Converge_to_map1.py`：2012 图资中存在、但 1996 年尚未设立的里，
应**并入其 1996 年时的母里**（同底色，且其間不画界线），避免地图出现「因行政沿革而留白」的破洞。

### 4.1 沿革表（`village_lineage_north4.py`）

新北市部分以 **AST** 从参考码抽出三张表（内容原样抄录，未修改）：

| 表 | 内容 | 规模 |
|---|---|---|
| `VILLAGE_SPLITS` | 母里 → 子里（**以乡镇为键**，新北乡镇名不重复） | 26 乡镇 / 518 组 |
| `VILLAGE_SPLITS_EXTRA` | 补充 | 87 组 |
| `VILLAGE_SPLIT_YEARS` | 子里成立年 | 41 笔 |

并入后共 **27 乡镇 / 605 组**；来源＝《臺北县志・地理志》村里沿革 + History.xlsx + 户政史料。

**基隆市／臺北市**（**以 (县市,乡镇) 为键**，因臺北/基隆有同名区：中正/中山/信义/大安…）
为使用者核对后提供，另收于：

| 表 | 内容 | 规模 |
|---|---|---|
| `VILLAGE_SPLITS_BY_COUNTY` | 2012 有、1996 未设立 → 母里（子里 1996 尚未设立 → 并入母里） | 12 区 / 36 组 |
| `VILLAGE_VOTE_MERGES` | 1996 有、2012 已无 → 承接之 2012 里（**得票数加总重算**） | 1 区 / 2 笔 |
| `VILLAGE_MERGED_INTO_NAMED` | 同上，但承接里「已有自身得票」，仅列报告 | 1 区 / 1 笔 |

### 4.2 主要函数

- `build_split_index(normalize, …)`：`(乡镇, 子里) → [母里…]`（新北，键不含县市）。
- `build_split_index_north4(normalize, …)`：`(县市, 乡镇, 子里) → [母里…]`（基隆／臺北）；键中 town 会
  **去尾缀**（七堵区→七堵）以对齐呼叫端的 `town_core`。
- `resolve_unit_name(...)` / `resolve_unit_name_north4(...)`：
  自身名在当年数据中存在 → 用自身；
  不存在且为已知「由母里分出」→ 往上追溯母里（可连续追溯）；
  **若已知成立年 ≤ 1996 → 不并入**（当年已设里，只是资料缺列），维持自身。
- `build_vote_merge_index` / `vote_merge_sources_2012` / `vote_merge_note`：跨里合并（1996→2012）。
- `repair_json_vill_name(county, town, village)`：村名修补（见 §5）。

### 4.3 主脚本衔接

- `unit_core = resolve_unit_name*  (...)  `，新北用旧表、基隆／臺北用 `_north4` 表；`match_type = "merged:母里"`。
- **跨里合并**：2012 里本身无 1996 资料（如臺北大安 学府 ← 1996 的青峰+农场）时，改读
  `1996總統副總統選舉_縣市鄉鎮村里.xlsx`「村里層級明細」的**得票数**，多里**加总后重算得票率**
  （`match_type = "merged:青峰+農場"`）。
- ① 村里界线改以「**当年行政单元**」为单位绘制：
  `villages.dissolve(by= COUNTYNAME|TOWNNAME|unit_core)` → **合并单元其間不画界线**，同色连成一片。
- 空 `unit_core` 逐列加 index，避免误并。

## 5. 改造四：村里名修补（JSON 罕见字还原）

**关键发现**：`twvillage2012.json` 把 Big5 无法表示的罕见字存成 **私用区(PUA)码位**，或以 **■(U+25A0)** 代替。

| 类型 | 码位 / 原字 | 还原 | 出现处 |
|---|---|---|---|
| PUA | `U+E6FF` | 峰 | 瑞芳爪[峯]、土城[峯]廷、新店五[峯] |
| PUA | `U+E8D7` | 腳 | 万里崁[腳] |
| PUA | `U+EE8E` | 濂 | 瑞芳[濂]新、[濂]洞 |
| PUA | `U+EEBE` | 館 | 板桥公[館]、三峡永[館] |
| ■ 占位符 | 6 笔逐一指定 | 瓦窯/灰窯/石槽/羌寮/新部/糖部 | 中和/坪林/树林/永和/万华 |

- PUA 码位可**全域**对应（`JSON_PUA_TRANS`）。
- **■ 一字多义，无法全域对应** → 用 `JSON_NAME_REPAIR = {(县市, 乡镇, 原名): 正名}` 逐一指定，
  正名依 1996 得票资料核对。
- 1996 资料侧另有异体字（中和「灰嗂」），加 `VARIANT_CHAR_MAP_1996 = {嗂→窯}` 再收敛一次。
- 全四县市共 **14 笔**修补（新北 13 + 臺北 1）。

> **踩坑记录**：一开始误判为「罕字整字遗失、名变短」（终端里 PUA 字被吃掉，看起来像 `永里`/`爪里`）。
> 实际字都在，只是以 PUA 储存 → **别用肉眼在终端判断乱码**，直接打印 codepoint 才看得出真相。

主脚本 `repair_base_names()` 就地改写 `VILLNAME`，另存 `VILLNAME_RAW`（原名）与
`NAME_REPAIR`（「原名 → 正名」），供报告第 4 节逐笔核对。

### 5.1 1996→2012 的「更名」（同一单元改名，非拆併）

除罕见字外，还有一类是**同一行政单元改名**：1996 年的乡名/村名在 2012 底图已换新名。
这与「沿革合并（拆併）」不同，是 **1 对 1 改名**，用「得票资料读入时改写成 2012 底图名」处理最干净。

| 县市 | 1996 乡镇市區 | 1996 村里 | → 2012 乡镇市區 | → 2012 村里 | 沿革 |
|---|---|---|---|---|---|
| 高雄市 | 三民（原高雄县三民乡） | 民族 | 那瑪夏區 | 南沙魯里 | 1957 三村改名民族/民权/民生 → 2007 乡改「那玛夏」、2008 三村复旧名 |
| 高雄市 | 三民 | 民權 | 那瑪夏區 | 瑪雅里 | 民权 → 玛雅（Maya） |
| 高雄市 | 三民 | 民生 | 那瑪夏區 | 達卡努瓦 | 民生 → 达卡努瓦（Takanua），2012 底图此里**无「里」字尾** |
| 高雄市 | 桃源（原高雄县桃源乡） | 梅蘭 | 桃源區 | 拉芙蘭里 | 1998 由樟山村分出梅兰村 → 2009 正名拉芙兰（Lavulang） |

- 表：`village_name_repair.TOWN_VILL_RENAME_1996`，键 = `(县市_core, 乡镇_core_1996, 村里_core_1996)` → `(乡镇_core_2012, 村里_core_2012)`。
- 函数：`rename_town_vill_1996(county, town, vill)`；在 `load_vote_data()` 建键前调用（`Draw_South2_President_1996.py`）。
- **关键坑**：必须用 `(县市,乡镇,村里)` **三元组**为键。只做乡镇名对照会把 1996「高雄县三民乡」与 2012「高雄市三民區」混为一谈（两者去尾缀后都是「三民」）。
- 报告新增 **第 5b 节**列出更名对照（与跨里合併的 5b 同号，视脚本而异）。
- 效果：高屏 無資料 58 → **54**、精確 1304 → **1308**、反向缺漏 29 → **25**。

## 6. 匹配与缺资料回报

### 6.1 匹配顺序（`nat.fuzzy_lookup` + 沿革）

1. **精确**：`(县市, 乡镇, 村里)` 三者正规化后完全相同。
2. **跨里合并**（2012 里 ← 多个 1996 里）：以得票数加总重算 → `merged:青峰+農場`。
3. **沿革合并**：用 `unit_core`（母里）去匹配 → `merged:母里`。
4. **模糊**：异体字 / 近似（要求等长 + 单字差异）。
5. **无资料**：以上皆失败 → 地图留白（纯白）。

### 6.2 稽核报告（`write_missing_report()`，6 节 + 5b）

| 节 | 内容 |
|---|---|
| ① | 地图有图斑、却对不上得票资料（留白）＋ **母里（说明栏）** ＋ 依县市统计 |
| ② | 模糊匹配（异体字/近似） |
| ③ | 得票资料有、底图无对应图斑（**反向缺漏**）＋ **已并入之 2012 里（说明栏）** |
| ④ | 底图村名修补（PUA / ■ 还原）——**校對表** |
| ⑤ | 村里沿革合并（子里 / 母里 / 成立年 / 母里是否在 1996 资料）——**校對表** |
| 5b | **跨里合并（1996→2012 反方向）**——校對表 |
| ⑥ | 各县市比对统计 |

反向缺漏的算法：`used = {(county, town, matched_vill) for 已匹配列}`，再取
`vote_dict` 中属于目标县市、却不在 `used` 的键。

## 7. 绘图管线（两层画法 + 油漆桶填色）

沿用 `Draw_North4_President_2016.py`（＝ `Draw_NewTaipei_President_2020.py` 系），本档只换图源与数据。

### 7.1 ① 线稿（1px 村里界）

`unary_union(单元边界)` → PIL Bresenham 逐段 1px 直绘 → `skimage.morphology.thin` 取中心线。

### 7.2 ② 区界 3px + 县市界/海岸线 5px

matplotlib(Agg, `DPI=100`) 绘区面与区界 → 以 `THRESHOLD_VAL=40` 二值化切掉抗锯齿灰边 → 纯黑线层。

- **微孔洞清理** `clean_tiny_holes(HOLE_MIN_AREA_M2=10000)`：填平 dissolve 浮点误差造成的散点。
- **迴针清理** `remove_ring_slits()`：折叠图资「去而复返」的退化迴针，避免 dissolve 后残留在
  区/县市外环、被误画成凭空冒出的死线（详见 `2016Precident/scripts/README.md` §5）。
- **两層同一像素网格约定**：像素 i 中心 = `minx+(i+0.5)/sx`，叠不错开 1px。

### 7.3 填色（油漆桶 / 洪水填充）

以线稿构成封闭堤坝，堤坝以外每一块 **4-连通区域整块填单色**，颜色取「区域内像素几何所
属村里的众数」→ **颜色永不跨越任何一条黑线**，密集村里区（如永和）不会出现错色。

- 取最高得票者填色；无资料（含 `VILLNAME` 空值）一律纯白 `nat.NO_DATA_COLOR`。
- 版面：`TITLE_LINES=[]` → **不画标题、不画图例**，只输出纯地图。

### 7.4 比例尺

1px = 20m（北北基宜 bbox 约 78×110 km → 约 3900×5596 px，长宽皆 < `MAX_PX=12000`）。
`SIMPLIFY_TOL_M=0`（不简化，避免把缓弯拉直）。

## 8. 出图后的自检（全绿才算完成）

1. **② 層 1px 原始线未被覆盖**：`_town_1px & ~dilate(town_layer)` 应 ≈ 0。
2. **② 層连通分量**：应为 `EXPECT_CC`（本岛 + 保留离岛），且 `<=40px` 小分量 = 0。
3. **油漆桶不变式**：非线连通区域中「非单色区域」= 0。
4. **几何参考比对**：与逐像素几何着色（GDAL/rasterio 中心规则，独立方法）差异 ≈ 0；
   **村外非白 = 0**；非允许色 = 0。

## 10. 已知的坑 / 待办

| 坑 | 症状 | 解法 |
|---|---|---|
| JSON 无内建 CRS | `to_crs` 报错 | 补 `EPSG:4326` 再投影 `EPSG:3826` |
| JSON 栏位小写 | 下游 KeyError | `load_base_map` 改名 `county/town/village → COUNTYNAME/...` |
| JSON 罕见字 PUA / ■ | 匹配不上、终端乱码 | §5 修补；**别肉眼判乱码，打印 codepoint** |
| 老县名 | 臺北縣 对不上 新北市 | `COUNTY_ALIAS`；乡镇尾缀交 `strip_town_suffix` |
| 行政沿革 | 2012 有、1996 无的里留白 | §4 沿革合并（四县市）；成立年 ≤1996 者不并入 |
| 沿革表用字与查表键不一致 | 索引对不上 | 索引建构时 **town 去尾缀、vill 去里/村尾缀** + `normalize` |
| 同名区（臺北/基隆都有中山/中正/信义区） | 沿革表撞键 | 基隆／臺北用 `(县市, 乡镇)` 为键的 `VILLAGE_SPLITS_BY_COUNTY` |
| 多 1996 里合为 1 个 2012 里 | 得票率不能直接取 | 读「村里层级明细」**得票数加总后重算**（§4.3） |

### 14.3 接縫對齊（`_apply_city_geojson`）——本節關鍵

兩份圖資的嘉義市互有出入（實測：`S_12` 59.66 km²、`S_pre` 59.62 km²、

```
① 逐里裁剪：pre2010 各里 geometry ∩ S_12          → 村里線不越出 2012 市界
② 市界補塊：S_12 −（各里聯集）的碎屑，逐塊併入最近的里 → 市界內零破洞（160 塊）
③ 區界硬切：每里再 ∩ 2012 東/西區區面             → 區界完全等於 2012
④ 區內貼合：每區「2012 區面 − 區內各里聯集」逐塊補入該區最近的里（177 塊）
```

**④ 為何必要（本次最大坑）**：`intersection` / `union` 會帶來坐標精度漂移，

變成嘉義市中心一條縱貫南北的假粗線（肉眼極明顯）。補上 ④ 後，每區里聯集**精確等於**
2012 區面 → 兩區必然共邊貼合、市側聯集 **1 塊**，假粗線消失。

> 附帶影響：`strip_far_parts` 重建 `MultiPolygon` 時，union 後的幾何可能含
> `LineString`/`Point` 非面殘留而拋 `TypeError`。已改為**只收面狀組件並展平**。

### 14.5 迴針（死角死線）核查——對照 2016 版 §5

> 2016 版 §5 記錄的新竹市香山區「迴針死線」是 `dissolve` 把圖資退化的「去而復返」

**方法**（同 §5.2～§5.5）：① 用腳本自身的 `_despike_ring`（權威判準，`tol≤5m`、
