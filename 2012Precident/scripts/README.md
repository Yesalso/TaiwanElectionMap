## 2. 與 2008 版的差異（本次全部改動）

### 2.1 候選人：2 強 → 3 強（增列親民黨）

2012 第十三任登記**三組**：
**蔡英文／蘇嘉全(01,民主進步黨)**、**馬英九／吳敦義(02,中國國民黨)**、**宋楚瑜／林瑞雄(03,親民黨)**。

> 與 2008（兩強）不同，本屆**候選人數 2→3**，故除換名外，`RATE_COLOR_STOPS` 需**增加第 3 組**，
> 報告文案（「兩強」→「三強」）與明細得票數欄位挑選亦連鎖調整（見 §3.2 與 SOP §4）。
> `CAND_NAMES` 順序**仍維持「藍（國民黨）→綠（民進黨）→橘（親民黨）」**，非 Excel 欄位順序。

```python
CAND_NAMES = ["馬英九", "蔡英文", "宋楚瑜"]   # 順序＝ RATE_COLOR_STOPS 順序，非 Excel 欄位順序
CAND_RATE_COLS = [f"{n}得票率" for n in CAND_NAMES]
```

> 號次政黨對照：`01＝蔡英文(民進黨)`、`02＝馬英九(國民黨)`、`03＝宋楚瑜(親民黨)`。
> 藍綠語義與 2008 相同（國民黨→藍、民進黨→綠），僅順序與組數調整；橘色為本屆新增。

### 2.2 配色（藍綠沿用 2008，新增橘）

| 組 | 候選人 | 政黨 | 色階（35% 起，5% 一階） |
|---|---|---|---|
| 1 | 馬英九 | 中國國民黨 | 藍 `#A6E9FF → #010D29`（35~100%，**12 階**） |
| 2 | 蔡英文 | 民主進步黨 | 綠 `#E8FFE0 → #071A09`（35~100%，**12 階**） |
| 3 | 宋楚瑜 | 親民黨 | 橘 `#FFF3E0 → #6E2600`（35~100%，**12 階**） |

> 第 1、2 組**逐字沿用** 2008 版；第 3 組直接抄自共用模組 `nat.RATE_COLOR_STOPS[2]`。

### 2.3 縣市名：`COUNTY_ALIAS` 全數清空

2012 得票資料之縣市名已是 **2010 縣市合併後名稱**（臺北縣→新北市、臺中縣市→臺中市、
臺南縣市→臺南市、高雄縣市→高雄市），與 `twvillage2012.json` 完全一致，
故六支腳本的 `COUNTY_ALIAS` **一律為 `{}`**（機制保留，僅內容清空）：

```python
COUNTY_ALIAS = {}   # 2012 資料已用「臺南市」（2010 縣市合併後名稱），與圖資一致
```

> 相較 2008 版仍需 `臺北縣→新北市` 等別名，本屆**無需任何縣市別名**。
> `nat.normalize_text`／別名查表機制仍保留，供未來換屆沿用。

### 2.4 嘉義市：**移除** pre2010，改回 2012 村里層

2008 版 `YCT4` 的嘉義市村里層採 `twVillage_pre2010.geo.json`（108 里）＋
`CITY_VILL_REPAIR {("西區","磚嗂里"):"磚窑里"}`。**2012 版整套移除**：
2012 得票資料的嘉義市為 **84 里**，與 `twvillage2012.json` 的嘉義市 84 里**逐字精確對上**，
故直接用 2012 底圖村里層，不再切換圖源。

> 連帶刪除：`CITY_GEOJSON`、`_apply_city_pre2010`、`CITY_VILL_REPAIR` 等機制（見 §7）。
> `("嘉義市","西區","磚■里") → "磚窯里"` 仍留在 `village_name_repair.py`，但 2012 資料無此列，不觸發。

### 2.5 那瑪夏／桃源：**移除**更名機制

2008 版 `South2` 以 `TOWN_VILL_RENAME_2008`／`rename_town_vill_2008` 處理
高雄那瑪夏、桃源等舊村名。**2012 版整套刪除**：2012 得票資料已使用新名
（南沙魯／瑪雅／達卡努瓦／拉芙蘭），與圖資一致，直接精確匹配即可。

### 2.6 北北基宜：沿革表**沿用機制、本屆自動失效**

`village_lineage_north4.py` 的沿革合併表（`resolve_unit_name_north4(year=2012)`）
以「該舊村里在 2012 資料是否仍存在」自我判定；2012 各里皆已存在，故本屆**沿革合併 0 筆**、
5b 報告列為空。機制保留待未來換屆（如選舉年早於設里年）再啟用。

### 2.7 臺中舊市區：得票過濾改以「縣市＋鄉鎮」配對

`json_oldcity` 模式會過濾得票資料，只留舊市區。因 2012 臺中市資料含**原臺中縣各鄉鎮**，
若僅以鄉鎮名（去尾綴）過濾，會誤收其他縣市同名之「東區／西區／南區／北區／中區」列。
本屆改以 **`(縣市, 去尾綴鄉鎮)` 配對** 過濾：

```python
_town_filter = {(c, nat.strip_town_suffix(t)) for c in TARGET_COUNTIES for t in TARGET_TOWNS}
# TARGET_COUNTIES = ["臺中市"]；TARGET_TOWNS = ['中區','東區','西區','南區','北區','西屯區','南屯區','北屯區']
```

> 過濾後臺中市得票列由 625 筆（全 29 區）收斂為 **214 筆**（舊市區 8 區），
> 與底圖 214 里完全對上、反向缺漏 0。`json` 模式則維持 `_town_filter = None`（全採）。

### 2.8 資料路徑與識別字全量替換

`2008總統副總統選舉_*.xlsx` → `2012總統副總統選舉_*.xlsx`；
輸出檔名／報告標題／`layer_name`／識別字（`VARIANT_CHAR_MAP_2008`→`VARIANT_CHAR_MAP_2012`…）
一併更名；檔名 `_2008.py` → `_2012.py`。

## 3. 改造方法論（可複用經驗，核心；詳見 SOP）

> 完整步驟見本目錄 **`README_改造SOP_總統得票率地圖.md`**。以下僅記本屆特別要點。

### 3.1 六階段流水線

```
① 讀上一屆 README（唯一藍本） ② 勘驗資料表與底圖（_inspect_*.py，跑一次即丟）
③ 機械替換年份/屆次/檔名（_convert*.py，正則守衛） ④ 定向替換候選人/色階/文案/底圖模式
⑤ 校驗：roundtrip 還原比對＋殘留掃描 ⑥ 執行 1 支 → 全跑 6 支 → 四項自檢
```

> 本屆步驟 ②③④⑤ 的一次性工具（`_inspect_data.py`、`_get_orange.py`、`_convert_gen.py`、
> `_convert_north4.py`、`_verify.py`）屬改造過程產物，**用畢已刪除**（依指示未另備份）。

### 3.2 候選人數 2→3 的連鎖清單

`CAND_NAMES` 由 2→3 時，已同步下列**全部**：`CAND_RATE_COLS`、`RATE_COLOR_STOPS`（增第 3 組）、
docstring 表頭、「兩強」→「三強」文案，以及**明細得票數欄位挑選**（務必依 `CAND_NAMES` 逐名挑選，
否則多餘候選人得票數會汙染跨里合併加總）：

```python
cnt_cols = [next(c for c in dc.columns if c.endswith("_得票數") and c.startswith(n))
            for n in CAND_NAMES]
```

### 3.3 機械替換的「三重保護」

1. **正則守衛**：`2008` 會出現在 `12000`、底圖年代等字串，須邊界鎖定
   `RE_2008 = re.compile(r"(?<!\d)2008(?!\d)(?!\.0)")`。
2. **roundtrip**：新檔還原（`2012→2008`、`第十三屆→第十二屆`）後須與原檔**逐字元相同**。
3. **殘留掃描**：替換後 grep 舊標記（`馬英九／謝長廷` 之外，2012 沿用「馬英九」須特別小心；
   掃 `謝長廷`、`pre2010`、`TOWN_VILL_RENAME`… 確認歸零）。

### 3.4 生成器與產出腳本「雙寫」陷阱

`_gen_2012.py` 內建 HEADER 模板（含 `CAND_NAMES`／色階／docstring），而產出腳本各自再帶一份。
改候選人/色階/文案時，**生成器模板與 6 支腳本都要改**，否則「重生成」會產生 diff。
改完後重跑生成器，用 roundtrip／`md5` 比對是否**逐字元相同**作為驗收。
