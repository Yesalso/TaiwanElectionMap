> 目的：讓未來各年（2020、2024…）的不分區政黨票原始資料，都能依同一套流程
> 變成（1）每縣市一個 `得票率.xlsx`（2）全台 368 鄉鎮市區得票率地圖。
> 已依此流程完成：**2008、2012、2016**。

## 二、原始資料格式（三種，都要從「檔內」取縣市名）

> ⚠️ 各地下載的 `xls` 檔名常是亂碼（編碼問題），**不要依賴檔名**，
> 一律以 `pd.read_excel(path, header=None)` 讀第一列標題來抓縣市名。

| 屆別 | 年份 | 原始檔 | 標題 → 縣市名 | 政黨名稱列 | 政黨儲存格樣式 |
|---|---|---|---|---|---|
| 七 | 2008 | `p10_T4_*.xls`（高雄縣/市、臺中縣/市、臺南縣/市 **分檔**，共 25 檔） | `選舉(.+?)各政黨` | 第 4 列（0-based），純 `中國國民黨` 字樣 | 固定位：有效 15 / 無效 16 / 投票 17 |
| 八 | 2012 | `立委-A05-6-(縣市).xls`（22 檔） | `選舉(.+?)各政黨` | 第 2 列 | `1\n \n民主進步黨` → 去「純數字行＋空白行」取第一個 |
| 九 | 2016 | `立委-A05-6-(縣市).xls`（22 檔） | `選舉(.+?)各政黨` | 第 2 列 | `1\n \n民主進步黨`（同 2012） |
| 十一 | 2024 | `第11屆…各投開票所得票數一覽表.xlsx`（22 檔） | `選舉各政黨在(.+?)各投開票所` | 第 2 列 | `(1)\n\n小民參政歐巴桑聯盟` → 去「`(N)` 行＋空白行」取第一個 |

共同結構（以 A05-6 為例，見 `scripts/convert_2016_to_rates.py` 註解）：

- 第 0 列：標題（含縣市名）。
- 第 1 列：欄名（`鄉(鎮、市、區)別 | 村里別 | 投票所別 | 各政黨得票情形 …`；2024 為 `縣市 | 鄉(鎮、市、區)別 | 村里別 | 投開票所別 …`）。
- 第 2 列：政黨名，自第 3 欄起；政黨數每屆不同（2008=12、2012=11、2016=18、2024=16）。
- **「有效/無效/投票」欄位位置隨政黨數浮動**：
  `有效票數 = 政黨起欄(3) + 政黨數`，其後依序無效票數、投票數（見下）。2008 是舊版固定欄位，勿混用。
- 「總計」列（A05-6 在第 5 列）：`政黨數不固定`，故搜尋 col0 含「總」字的第一列；之後才是各列資料。
- 資料列規則：**col0 非空、col1 空** → 鄉鎮市區小計列（更新 `cur_district`）；**col1 非空** → 村里/投票所列（col1=村里、col2=投票所；2024 為 col2=村里、col3=投票所）。鄉鎮小計列的 col0 是 `\u3000\u3000`（全形空白），不能拿來當區名。

```python
parties = []                      # 從第 2 列、第 3 欄起逐欄
for col in range(3, df.shape[1]):
    cell = df.iloc[2, col]
    if is_blank(cell): break
    lines = [ln.strip() for ln in str(cell).split("\n")
             if ln.strip() and not ln.strip().isdigit()]   # 2016 無括號；2024 另有 "N)"
    parties.append(lines[0])
n = len(parties)
valid_col, invalid_col, polled_col = 3 + n, 3 + n + 1, 3 + n + 2
# 縣市名（依屆別選對 regex）
county = re.search(r"選舉(.+?)各政黨", str(df.iloc[0, 0])).group(1)
```

**村里級合併**：2012/2016 的轉換器會把同一「鄉鎮×村里」的各投開票所**得票數加總**，
再以 `得票數 ÷ 有效票數 × 100` 算得票率（2008 舊版未合併，逐所列）。

### 產出 `data/{year}{縣市}_得票率.xlsx`（3 個工作表）

| 工作表 | 內容 |
|---|---|
| `各里彙總` | 選舉區別、鄉鎮、村里、`<政黨>得票率`、有效票數A |
| `各鄉鎮(市、區)彙總` | 選舉區別、鄉鎮、`<政黨>得票數`、`<政黨>得票率`、有效/無效/投票數 |
| `縣市彙總` | 同上，縣市*1 列 |

## 三、製圖（County 資料夾）

### 1. 複製模板

```powershell
Copy-Item County\2016LegislatorParty.py County\{year}LegislatorParty.py
```

### 2. 必改 5 處

| 常數 | 說明 |
|---|---|
| `DATA_DIR` / `OUT_PNG` | 指向 `{year}Legislator-at-Large\data`；檔名 `{year}年立法委員選舉_得票率地圖.png` |
| `OLD_COUNTY_MAP` | 縣市名對應（見下表），**全 22 縣市都要在 map 內**，否則會被當「無資料」跳過 |
| `RATE_COLOR_STOPS` + `CANDIDATES` | 各「會領先」政黨的色階組（藍=中國國民黨、綠=民主進步黨、粉紅=無黨團結聯盟…）；圖例只畫有領先鄉鎮的政黨 |
| `TITLE_LINES` / `TAG` | 屆次、日期（國字）、始祖款避免用「政黨比例代表」，用「**全國不分區及僑居國外國民選舉**」 |

### 3. 縣市名對應（依年份）

```python
# 2008（舊縣市制，2010 五都改制前）：
{ "臺北縣":"新北市",   "桃園縣":"桃園市",   "臺東縣":"台東縣",
  "臺中縣":"台中市",   "臺中市":"台中市",
  "臺南縣":"台南市",   "臺南市":"台南市",
  "高雄縣":"高雄市",   "高雄市":"高雄市",   # …其餘同名 }
# 2012（五都後、桃園升格前）：僅 {"桃園縣":"桃園市"} 要改，其餘同現行
# 2016 之後：全部同現行（桃園市已升格），map 只是身份映射
```

- `VARIANT_CHAR_MAP`：`臺→台、裡→里、侖→崙、穀→谷、樸→朴、恒→恆、莊→庄、鬥→斗、褔→福`（對照表 vs 資料異體字）。
- `VARIANT_WORD_MAP`：`後里→后里`、`滿洲→滿州`。
- `SPECIAL_TOWN`（≤2008 才需要）：`("高雄縣","三民")→"那瑪夏"`（與高雄市三民區區分）。
- 全台一致用鄉鎮市區層級而非村里，因村里歷年更名太多會大量無法配對。

| 屆 | 選舉日 | 羅馬數字用法 | 主要領先政黨（鄉鎮層級） |

| 第七屆 | 2008-01-12 | 中華民國九十七年一月十二日 | 中國國民黨 267 / 民主進步黨 101 |

## 四、執行與檢查

```powershell
python "2016Legislator-at-Large\scripts\convert_2016_to_rates.py"   # 每縣市應輸出「村里 xxx 鄉鎮市區 xx」
python "County\2016LegislatorParty.py"
```

腳本自我檢查輸出要相符（標準值）：

```
對照表鄉鎮市區    : 368 個（全市縣 22 個）
有資料(填色)      : 368          ← 少於 368 表示配對失敗
無資料(不著色)    : 0            ← 有值就要查 OLD_COUNTY_MAP / 異體字
各候選人領先鄉鎮數: …（合計 368）
```

程式化粗驗（藍/綠像素比例；`maps` 中已有檔案可先對照）：

```python
import numpy as np
from PIL import Image
a = np.array(Image.open("maps/County/2016年立法委員選舉_得票率地圖.png").convert("RGB")).reshape(-1,3)
def cnt(pal):  # pal: ["#RRGGBB",…]
    m = np.zeros(len(a), bool)
    for c in pal:
        m |= np.abs(a.astype(int)-np.array([int(c[1:3],16),int(c[3:5],16),int(c[5:7],16)])).sum(1) <= 6
    return int(m.sum())
```

> 因為 AI 無法直接「看」圖片，務必用上述像素統計 + 統計數值做為驗證手段。
