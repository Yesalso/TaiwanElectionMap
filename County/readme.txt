================================================================================
  鄉鎮市區選舉結果地圖生產器（County）— 設計說明
================================================================================

【專案目的】
本專案以「全台單一張底圖 ＋ 顏色對照表」取代傳統的 SHP 圖資繪圖流程，
只需把得票率資料對應到各鄉鎮市區，即可批次產生「全台 22 縣市、368 個
鄉鎮市區」的選舉得票率地圖（例如：某政黨在各鄉鎮市區得票比例圖）。

--------------------------------------------------------------------------------
【目錄檔案說明】
--------------------------------------------------------------------------------
County/
    Colorful.png                      全台鄉鎮市區唯一色底圖
    Name_Color_Correspondence.xlsx    顏色 ↔ 鄉鎮市區 對照表（含縣市碼表）
    readme.txt                        本檔（設計與使用說明）

（1）Colorful.png
    - 影像尺寸： 3955 × 5033 像素，RGBA。
    - 內容： 全台 22 縣市、368 個鄉鎮市區，每個鄉鎮市區以「一種獨一無二的
      純色」填滿（不與其他鄉鎮重複），因此顏色本身即為該鄉鎮的身分識別碼
      （ID Key），可用於掃描辨識每一個鄉鎮的像素區域。
    - 全圖共 421 種顏色：其中 368 色 = 368 個鄉鎮（與 Excel 對照表一一對應）；
      其餘為版型環境色與雜點：
        * #323232       海洋／畫布背景
        * #7F7F7F       陸地底色（不屬任何鄉鎮多邊形的區塊）
        * #FFFFFF 等    碎小雜點（文字／反鋸齒殘留）
    - Excel「面積 (圖元)」欄即為該色在底圖上的實際像素數，二者互相驗證。

（2）Name_Color_Correspondence.xlsx
    主表格欄位（每列一個鄉鎮市區，共 368 列）：
       區域 ID       該縣市內的流水編號（各縣市各自從 1 起算）
       填充顏色(HEX) 底圖上該鄉鎮的唯一顏色（即 Colorful.png 中的填色）
       面積(圖元)    該鄉鎮在底圖上的像素數
       中心 X / 中心 Y  該鄉鎮像素區域的形心座標（可再用於標示地名）
       縣市編碼       縣市代碼（1–22）
       全域 ID        全台流水編號（1–368，跨縣市唯一）
       地名          鄉鎮市區名稱（如：北投區、員林市、秀林鄉……）
    表格右側另附「縣市碼表」：縣市編碼 1–22 ↔ 縣市名稱
     （臺北市、新北市、桃園市、臺中市、臺南市、高雄市、新竹縣、苗栗縣、
      彰化縣、南投縣、雲林縣、嘉義縣、屏東縣、宜蘭縣、花蓮縣、臺東縣、
      澎湖縣、基隆市、新竹市、嘉義市、金門縣、連江縣）。

--------------------------------------------------------------------------------
【設計思路】
--------------------------------------------------------------------------------
核心概念：「底圖色 = 鄉鎮身分證」。Colorful.png 用顏色標記每個鄉鎮，
Name_Color_Correspondence.xlsx 把「顏色 ⇄ 鄉鎮」綁定成一本字典，
後續所有程式只要做兩件事：

    1. 對底圖：掃描像素 → 由顏色查「顏色→鄉鎮」→ 知道這是哪個鄉鎮。
    2. 對資料：以「地名」欄把得票率表掛到鄉鎮上 → 知道這個鄉鎮該塗什麼色。

優點：
    - 不需 SHP／GeoDataFrame 幾何繪圖，全台一張底圖即可批次換色。
    - 鄉鎮對應關係集中在一份表，新增／修正顏色或鄉鎮名只需改一個檔案。
    - 換色可用 numpy 把「顏色→繪圖色」做成查表，對整張圖做 pixel 查詢替換，
      速度快且記憶體可控。

--------------------------------------------------------------------------------
【未來程式流程（建議介面）】
--------------------------------------------------------------------------------
  步驟 1  讀入 Colorful.png
          └─ 以 RGBA 讀入，轉成 3955×5033 的 RGB 陣列備用。

  步驟 2  讀入 Name_Color_Correspondence.xlsx，建立三份索引：
          └─ color→(縣市編碼, 全台ID, 地名)     用於查底圖像素
          └─ 地名→color                         用於把資料掛回底圖
          └─ 縣市編碼→縣市名                    用於分縣市統計／描縣界

  步驟 3  輸入得票率資料（使用者維護的表格，每鄉鎮一列）：
          └─ 建議欄位：縣市, 鄉鎮市區, 得票率1, 得票率2, 得票率3（%）。
             （粒度為「鄉鎮市區」，不需要村里；格式可沿用本倉庫其他選舉
               專案的 Excel 慣例，如 縣市/鄉鎮市區/區里/得票率…，只是
               區里層級可以省略或留空。）

  步驟 4  名稱匹配：
          └─ 以「地名／鄉鎮市區」欄與 Excel 對照表做正規化比對
             （去鄉鎮市區尾碼、NFKC 正規化、去掉異體字，必要時做模糊匹配，
               參考本倉庫現有腳本的 normalize_text / fuzzy_lookup 寫法），
             把得票率正確掛上每個鄉鎮。

  步驟 5  依得票率算「繪圖色」：
          └─ 沿用現有色階規則：三個得票率取最大者決定所屬色系，
             再依數值落在哪一級決定深淺色（例如 藍=得票率1、綠=得票率2、
             灰=其他；無資料的鄉鎮塗灰色）。
             （色階 color_stops 可沿用 高雄總統含乡镇市区.txt 等既有腳本
              的設計。）

  步驟 6  全圖換色：
          └─ 對 Colorful.png 逐像素：底色若落在「顏色→鄉鎮」索引中，
             即以該鄉鎮的繪圖色覆寫；背景 #323232、陸地底 #7F7F7F、
             邊線與雜點維持原樣（或另行處理）。

  步驟 7  後製（非必要但建議）：
          └─ 用既有「黑帶 buffer」手法加粗鄉鎮界／縣市界與外輪廓
          └─ 填平白色小雜點（fill_small_white_blobs）
          └─ 右側加圖例（色階色塊 + 「無匹配數據」灰格）
          └─ 依需要加標題文字、比例尺
          └─ 輸出成指定檔名的 PNG

【備註】
--------------------------------------------------------------------------------
- 若色表與底圖不一致（新增縣市、更新邊界），「面積」與像素數會對不起來，
  可用「全圖像素顏色分布 → 與 Excel 顏色清單比對」自動檢查缺漏。
- 得票率表請務必維持「每鄉鎮一列」，且欄位（縣市／鄉鎮市區／得票率…）
  名稱固定，程式才能穩定解析。
