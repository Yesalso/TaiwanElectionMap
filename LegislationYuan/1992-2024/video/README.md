## 二、版面骨架

```
y   32 – 192   頁眉左半  01 國旗白卡 ｜ 02 主標題 ｜ 03 年份圓盤（高 160，按內容走）
y   32 – 268   頁眉右半  04 席次統計卡（滿帶 236）
y  208 – 1404  左內欄    05–10 四張政黨卡（656×156）→ 其他政黨（170）→ 原住民（322）
y  284 – 1404  中段      11 主圖 1 ＋ 12 輔圖 1 ｜ 13 主圖 2 ＋ 14 輔圖 2（582×1120）
y  284 – 1404  右內欄    15–19（被 04 的下緣 268 壓住，所以比左內欄低 76）
y 1404 – 1440  文件說明  取消頁尾後只剩這 36px，骨架圖說明改成兩行 8–9px
```

**頁眉刻意是階梯狀**：左半（國旗／標題／圓盤）只 160 高、按內容收住，
右半的席次統計卡才是滿帶 236。下方的欄位跟著各自上方的頁眉走 ——
左內欄 208 起、地圖與右欄 284 起，中間 76 的錯位是刻意保留的，
不是沒對齊。

頁眉高 **236**，與 2022 縣市長看板的頁眉同高（`layout.js` 的 `header.h`），
四件套的順序也照它：**國旗卡 → 標題 → 年份圓盤 → 右側統計**；
本來右側放的是「四行數據 ＋ 時任首長」，這裡換成立法院的主角 **席次統計**。

上緣留白 32、左右與下緣 72；模組間距 16–40；左右兩欄刻意不等寬（左 620 / 右 488），
因為左欄要放「照片位 + 黨名 + 得票率 + 票數 + 席次牌」五行，
右欄只放大字（見 §四 卡片內部構成）。

## 四、卡片內部構成（參數在 `layout_board.CARD`，渲染器與骨架圖共用）

```
┌── 05 ──────────────────────────────────────────────────────────┐
│ ┌────────┐  DPP｜區域                    11（0.58 白）           │
│ │        │  民主進步黨                   25 / 900               │ ┌────────┐
│ │ 照片位 │  主席 賴清德                   16.5（標籤 0.58／名字 0.82）│ │ 席次牌 │
│ │ 98×120 │  45.17%          603萬5971票  42 政黨亮色＋同色光暈  │ │ 36     │
│ └────────┘                               14/10 .66 右對齊      │ └────────┘
└────────────────────────────────────────────────────────────────┘
```

- **得票率是卡片的主角**（42 vs 黨名 25 ≈ 1.7 倍）—— 立法院不分區是「黨 > 票」，
  所以黨名壓住、百分比放開；縣市長看板剛好相反（人 > 票）。
- 得票率用**政黨亮階**（KMT `#5f96ea`／DPP `#4fc47c`／TPP `#00d9ca`／NPP `#ffd23f`）
  ＋**同色光暈**，不是白字、也不是黑陰影（照 2022 主卡的做法）。
- 票數走**富文本**：數字 14／`萬`、`票` 10，`603萬5971票`（不是 `6,035,971 票`）。
- 席次牌**實色直角、無框、純數字**（沒有「席」字、沒有「區域席次」標籤）；
  數字大小 1.05×牌高，超過牌寬 84% 才等比縮；牌面亮度 > 150 時自動改深字
  （時代力量黃牌、無黨籍灰牌）。
- **主席**：投票日當天的政黨主席，格式固定「主席 〇〇〇」；無黨籍沒有主席 → 印「—」。
- 08/17/18 是窄卡：`k = (h−20)/120` 整組等比縮，但**照片位比例不變**（0.82 : 1）。

## 七、已知風險

1. ~~**輔圖會壓到本島西北角（約 37%）。**~~ **已修（2026-11-19）**：
   輔圖移到主圖東南海面 `(1100,1014)`、尺寸 200×250，實測墨跡重疊 0.3%
   （只剩幾顆 1px 小島點）。處理方式就是設計分析 §7.2⑦ 的第 ② 案
   「移到框外／框內的空水域」——把「壓」變成「不壓」。
   量法是「框 vs 墨跡」，不是「框 vs 框」：本島在 600 寬的框裡只有 563 寬
   （左右各空 18），用框算會低估覆蓋率。
2. **地圖素材是「海報」，不是看板素材。**
   `map/*.png` 是 3203×4404 的海報：左上角有大陸輪廓、左欄有標題＋圖例＋三個離島小圖。
   直接貼上板會重演 2022 的「海報標題與看板頁眉打架」。
   要先寫裁切／去背腳本（比照 `board/src/tools/build_national_assets.py`：
   挖大陸、黑線轉白、共裁切框），並把「本島」與「左欄三格」分別輸出給主圖／輔圖。
3. **1992–2004 與 2008+ 的口徑不同，席次也差很多。**
   早期是「區域＋不分區混合」的政黨得票，後期是分開的政黨票；
   席次 161 / 164 / 225 vs 113。04 席次卡目前只排 5 列，225 席那幾屆要能自動長列。
4. **骨架圖的內部灰條是壓縮過的。**
   編號／名稱條佔用框內上緣 30–42px，卡片內的照片位、席次牌因此等比縮小。
   **比例是對的，絕對尺寸看卡片左上那行 spec** —— 那行字已改由
   `layout_board._party_spec()` 從 `CARD` 現算，不再手抄（2022 骨架圖的教訓）。

### 12.1 卡片＝六件東西，多一件少一件都不算對

```
┌──────┬────────────────────────────────────┬──────┬────────┐
│      │  民主進步黨         主席            │      │        │
│ 照片 │                     賴清德    ◯    │  36  │        │
│      │  603萬5971票    45.17%              │      │        │
└──────┴────────────────────────────────────┴──────┴────────┘
 照片框      黨名／票數 ／ 主席＋得票率        黨徽   深一階黨色席次塊
```

| # | 元素 | 規則 |
|---|---|---|
| ① | 照片框 | 空的圓角框（淡一階黨色 ＋ 亮框線），照片由後製合成 |
| ② | 黨名 | 主角，白字／深字 900，字級上限 `0.48 × 卡高`（實際由寬度反解，見 12.2） |

### 數字字型（Noto Sans TC）

PIL 沒有 CSS 的「逐字回退」，所以不能只換一個 family 就了事。
`blank_board.Board.text()` 的做法：

1. `split_digits("第 11 屆")` → `[('第 ',0),('11',1),(' 屆',0)]`
2. 每段用各自的字型量寬、逐段推進 x（`measure()` 也是同一套算法，
   否則 `fit_text` 會低估寬度、把字縮過頭）
3. 垂直方向先換算成**基線**再畫（`a → y+ascent`、`m → y+(ascent−descent)/2`、
   `d → y−descent`、`s → y`），用 `anchor="ls"` 逐段落字 ——
   兩支字型的 ascent 不同，直接用同一個 `la` 會一高一低。

字型查找順序（`NUM_FONT_CANDIDATES`）：

| 順序 | 檔案 | 狀態 |
|---|---|---|
| ① | `video/assets/fonts/NotoSansTC-Black.otf`（或 `-Bold`） | **未安裝**；丟進這個資料夾就會自動優先採用 |
| ② | `%LOCALAPPDATA%\Microsoft\Windows\Fonts\NotoSansUI-Black.ttf` | 目前實際使用（900，2022 看板「2022／11 月 26 日」那支） |
| ③ | `C://Windows//Fonts//Noto Sans SC.ttf` | 後備（拉丁字形與 TC 相同，但只有 Regular） |

> 本機沒有 Noto Sans TC（也沒有 TC 的靜態字重可下載），所以現階段落在
> **Noto Sans UI Black**：同一套 Noto Sans 拉丁字形、Black 字重，與板上其他 900 字重相稱。
> 若之後裝了 TC，把 `NotoSansTC-Black.otf` 放進 `video/assets/fonts/` 即可，
> 不需要改任何程式碼；渲染結果會與現在**幾乎相同**（數字字形本來就一樣）。
