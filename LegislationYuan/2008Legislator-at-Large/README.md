## 二、繪圖管線（四步）

繪圖邏輯完全沿用 `Draw_South2_President_2020.py` 的「線稿兩層 + 洪水填充」做法
（不使用早先的 matplotlib 分層直繪 + 顏色量化）。共用模組取自
`Precident/2024Precident/scripts/20/Draw_National_President_2024.py`
（`flood_fill_layer` / `check_region_single_color` / `full_geom_check`）。

```
① 線稿（兩層）
   村里界 1px ：PIL Bresenham 逐段直繪 → skimage.morphology.thin 取中心線
   區界 3px / 縣市界·海岸線 5px：matplotlib(Agg, DPI=100) 繪面與邊，
       以 THRESHOLD_VAL=40 二值化切掉抗鋸齒灰邊 → 純黑線層
   前置清理：remove_ring_slits（迴針）+ drop_degenerate_holes（退化內環）
② 填色（洪水填充）
   以 lines_mask 為封閉堤壩，堤壩以外每一塊 4-連通區域整塊填單色，
   顏色取「區域內像素幾何所屬村里」的眾數 → 顏色永不跨越任何一條黑線
③ 立委選區界 5px（白）——本圖專屬規則（見第三節）
④ 疊線
   先 arr[lines_mask] = 0 畫黑線，再 arr[立委白線] = 255
```

## 三、立委選區界白線規則

> **立委選區界統一畫白線 5px；僅在與「縣市界（含海岸線）」重合的段，讓位給黑色縣市界。**

- 作法（**幾何法**）：先把「與縣市界/海岸線重合」的段自立委界折線中剔除，再對剩餘內部段做 5px 緩衝帶。

```python
white_line = district_boundary.difference(outer_boundary.buffer(half_w_m))
band_layer = render_poly_layer(white_line.buffer(half_w_m), ...)
```

- ⚠️ **關鍵前置**：`outer_boundary` 必須先做 `drop_degenerate_holes()`。村里界圖資相鄰兩里有時只差 <1 m 沒接上，`unary_union` 後會形成「面積≈0 的內環」，被 `.boundary` 當成海岸線；若不剔除，`difference` 會在立委白線**中段**挖掉一小塊，白線中間就會冒出黑點（鹽埕區/前金區交界即為此例）。
- 本圖只有一個縣市、5 個選區界全在內部，故立委界與縣市界**實際無重合段**；此規則已按通用方式實現，跨縣市圖會自動生效。

## 五、鐵律（改造過程中踩過的坑，改動前必讀）

> 以下為本專案反覆迭代後沉澱的經驗，**新增圖層或修改線寬規則時務必遵守**。

### 1. 粗白線 / 擦除帶一律用「幾何」運算，禁止像素遮罩相減

- **症狀**：縣市界/海岸線外圈出現約 1px 的**白暈圈**，白線看起來「大一圈」；部分區界黑線卡在白線中間。
- **根因**：`白帶 = 立委界 5px 帶 − 縣市界 5px 帶` 這種**兩個獨立渲染的像素遮罩相減**不精確——白帶是「無抗鋸齒的實心多邊形」（實寬 ≈5px），縣市界層是「抗鋸齒描邊線」（二值化後有效寬 ≈4px），兩者寬度不守恆，必然殘留約 1px 白邊。
- **正解**：改用 `difference / intersection` 等幾何運算，讓白帶**根本不接觸**縣市界/海岸線。

### 2. `.boundary` 當「外輪廓 / 海岸線」用之前，必須先剔除退化內環

- **症狀**：地圖內部憑空多出粗黑線；立委白線中段冒出黑點。
- **根因**：村里圖資相鄰兩里的**亞像素細縫**（本圖最小 0.8 m）經 `unary_union` 後形成面積 ≈0 的內環，被 `.boundary` 當成海岸線 → ① 被畫成 5px 粗黑線；② 立委白線做 `difference` 時，細縫周圍的緩衝把白線中段挖穿。
- **正解**：`drop_degenerate_holes(geom, min_area=HOLE_MIN_AREA_M2)` 填平面積 < 1 公頃的內環（本圖 33 個全為 0 m²，真正水域並不以「內環」形式存在，故安全）。要應用到**所有**外輪廓推導處。

### 3. 自檢必須回查「最終渲染像素」，不能只查派生遮罩

- **症狀**：舊自檢「白線帶內殘留黑線 = 0」一直報綠，但白線確實被打洞。
- **根因**：白線被打洞後，那幾像素已不屬於 `band_layer`，查詢「`band_layer` 內的黑像素」恆為 0 —— **假陰性**。
- **正解**：把 `difference` 剔除的非海岸碎片以 1px 折線光柵化，回查**最終圖像**該處是否真的變黑。

### 4. 線寬量測要用骨架法

- 列掃描的「連續黑段長度」會被斜線投影撐長而失真，不可靠。
- 正解：`skeletonize` + `distance_transform_edt`，骨架處距離 ×2 = 垂直於線的實際寬度。

### 5. 粗白線必須用 buffer 成像，禁用「線稿提取 + 逐段畫線」

- 逐段畫線會把圖資「去而復返」的退化迴針放大成肉眼可見的**悬空死線**。

### 6. 輸出 PNG 可能被預覽器占用

- 會拋 `OSError: [Errno 22]`，需加「重試」兜底。

## 六、自檢清單

腳本執行時會逐項輸出，全部通過才算成功：

1. **油漆桶不變式** — 每一塊非線區域皆為單色（非單色區域數 = 0）
2. **逐像素幾何參考差異** ≈ 0；**村外非白** ≈ 0
3. **全圖只含允許色**（政黨色 / 黑 / 白，非允許色 = 0）
4. **外輪廓無剩餘退化內環 = 0**
5. **白線帶內無殘留黑線 = 0**
6. **被剔除碎片不在白線路徑上留下黑像素 = 0**（防止「白線中段打洞」）
