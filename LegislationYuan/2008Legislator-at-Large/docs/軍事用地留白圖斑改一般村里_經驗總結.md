## 三、根因：不是 6px 縣市界，是「飛地 + 整圈描 2px」

### 3.1 關鍵量測：共邊長度

對每個圖斑去量「與各鄰接鄉鎮的共邊長度」：

```
清泉崗軍事基地（編在梧棲區）
  與同鄉鎮（梧棲區）其他里共邊：0.00 km      ← 飛地！根本沒跟梧棲區接壤
  與 清水區：7.65 km ／ 沙鹿區：2.92 km ／ 神岡區：2.25 km

岡山軍事用地（編在岡山區）
  與同鄉鎮（岡山區）其他里共邊：4.63 km      ← 正常：本來就是岡山區的里
  與 彌陀區：3.48 km ／ 梓官區：0.87 km
```

### 3.2 為什麼會「整圈粗線」

第②層鄉鎮界是這樣畫的：

```python
thick_town.boundary.plot(ax=ax, edgecolor="black", linewidth=town_lw, ...)  # 每個鄉鎮面「整圈」描
```

清泉崗那塊是 **梧棲區的孤懸部件**（`dissolve` 後 梧棲區 = MultiPolygon，2 個部件），
於是它的**整圈輪廓都被當成鄉鎮界畫 2px**；四周的清水／沙鹿／神岡三個鄉鎮面則是「凹口」，
凹口邊也各描一次。2px 再與 ① 層同位的 1px 村里界以**不同演算法**（matplotlib Agg vs
PIL Bresenham）成像、錯開約 1px 疊加 → 實際是 **3~5 px**。

而 6px 縣市界在這張圖只有 185 m 寬（30.8 m/px × 6）；3~5 px 與它**肉眼幾乎同級**，
所以「一整格空白被一圈粗線框住」看起來就像被縣市界圈起來。

### 3.3 岡山那塊為什麼不用改

它本來就是岡山區的里：**52% 的邊界已經是 1px 村里界**，只有靠彌陀區（3.48 km）、
梓官區（0.87 km）兩段是 2px 鄉鎮界 —— 這正是「正常村里」該有的樣子。
把這兩塊並排看，問題只在臺中那塊的**飛地身分**。

## 四、修法（+50 行，不動幾何）

新增常數 `EXCLAVE_TOWN_FIX` 與函式 `fix_exclave_village_towns()`，在 `load_base_map()`
最後呼叫 —— 把飛地村里**改掛回它實際所在的鄉鎮**（基地門牌本即「清水區」）：

```python
EXCLAVE_TOWN_FIX = {
    ("臺中市", "梧棲區", "清泉崗軍事基地"): ("臺中市", "清水區"),
}

def fix_exclave_village_towns(gdf, table=EXCLAVE_TOWN_FIX):
    """把「飛地村里」改掛到實際所在的鄉鎮市區（只改 TOWNNAME／COUNTYNAME，不動幾何）。"""
    out = gdf.copy()
    for (c, t, v), (nc, nt) in table.items():
        m = (out["COUNTYNAME"] == c) & (out["TOWNNAME"] == t) & (out["VILLNAME"] == v)
        ...
        out.loc[m, "COUNTYNAME"] = nc
        out.loc[m, "TOWNNAME"] = nt
        print(f"  飛地村里歸屬修正：{c}{t}{v} → {nc}{nt}（{k} 個圖斑；原本與 {t} 其他里共邊 0 m）")
    return out
```

改完之後的幾何效果：

```
梧棲區 dissolve 不再有孤懸部件 → ② 層不再沿它整圈描 2px
清水區 dissolve 納入這塊      → 它與清水區各里之間＝1px 村里界（7.65 km，59%）
                               → 與沙鹿區／神岡區之間＝2px 鄉鎮界（5.17 km，41%）
```

即「**正常的村里界線 ＋ 鄉鎮市區界線**」，而不是整圈飛地邊界。

選「清水區」而非沙鹿／神岡：共邊最長（7.65 km），且清泉崗基地門牌本即清水區，
歸屬同時也修掉了 2012 圖資的行政編屬錯誤。

## 五、診斷方法論（可複用）

這次真正花時間的是「**怎麼確認畫面上那條線到底是哪一層畫的、幾 px**」。可複用四招：

### 5.1 純白連通分量 → 定位留白區

```python
white = (a[:,:,0] == 255) & (a[:,:,1] == 255) & (a[:,:,2] == 255)   # 必須「全等」
n, lab, stats, _ = cv2.connectedComponentsWithStats(white.astype(np.uint8), 4)
# 濾掉貼邊的（＝海面）、濾掉面積太小的，剩下的就是留白圖斑
```

⚠️ **一定用「全等 255」而不是 `>=250`**：線色是 `#FCFCFC`＝(252,252,252)，
用 `>=250` 會把線網也算成白，於是白區沿線網一路連到海面，變成一個 16 萬 px 的巨分量，
**什麼都找不到**（第一次就踩了這個坑）。

### 5.2 線寬量化 → 判斷「這條線屬於哪一層」

線色與填色在 RGB 上可完全分離（線 252 / 無資料白 255），所以：

```python
line = (a[:,:,0] == 252) & (a[:,:,1] == 252) & (a[:,:,2] == 252)
w = 2 * ndimage.distance_transform_edt(line)     # 線寬 ≈ 2 × 距離轉換
```

把 `w` 上色（2px 綠／3px 黃／4px 橙／≥5px 紅）輸出成小圖，**一眼就能看出哪一段是粗線**，
比肉眼在 30.8 m/px 的巨圖上猜可靠得多。

### 5.3 geo → px 標定（量線寬的前提）

不必跑完整管線，用「**20 縣市幾何外框**」對「**著色像素外框**」標定即可：

```
本島（含澎湖）幾何 bbox： (77851, 2422122) – (351611, 2799146)   EPSG:3826
影像著色像素 bbox：       (89, 125) – (8984, 12375)              px
→ sx = sy = 0.032491 px/m（1 px = 30.8 m），誤差 < 1 px
```

用這個變換把任何圖斑／線段中點換成像素座標，就能在 PNG 上定點量線寬、定點裁圖。
（標定時要把左上角的連江／金門／烏坵附圖框挖掉，否則 bbox 會被附圖帶歪 —— 澎湖在
x≈1840，只挖 `x<1800` 會剛好切掉澎湖西側礁石，sx 會歪成 38.1 m/px。）

### 5.4 按「鄰接鄉鎮」分組取樣

沿圖斑邊界取 300 點，每點用 5×5 窗口量線寬，再按「這一點貼著哪個鄉鎮」分組統計。
這樣才能回答「**哪一段變細了、哪一段本來就該粗**」，而不是給一個平均值交差。

⚠️ 小窗口 EDT 會**飽和**（5×5 最大只到 5.0），所以這組數字只能做**相對比較**
（「≤2px 佔比」），不能當絕對線寬讀。

## 六、鐵律級教訓

1. **使用者的「縣市界」不必然是程式裡的 6px。** 這次全圖找不到任何 6 px 貼著那兩塊空白
   （貼邊線寬分布裡 6px 只有 1 個像素）。真正成因是「鄉鎮界 2px 被兩層重複疊合成 3~5px」。
   **先量化、再改**；若照字面去改 `LINE_COUNTY_INNER_PX`，會改錯地方且破壞縣市界。
2. **「留白」先查稽核報告，不要先在巨圖上找。** 8021 個圖斑的圖，找 4 個留白圖斑靠肉眼
   幾乎不可能；`write_missing_report` 早就逐筆列好了。
3. **飛地是 dissolve 類管線的隱形地雷。** 只要某鄉鎮在 `dissolve` 後是 MultiPolygon，
   ② 層 `boundary.plot()` 就會替那個孤懸部件描一圈鄉鎮界。**判斷法：量「與同鄉鎮其他里的
   共邊長度」，0 m 就是飛地**。任何「按鄉鎮／縣市整體描邊」的圖層都要想到這一層。
4. **同一條邊被兩層畫兩次、寬度不同 → 疊成更粗的線。** matplotlib 與 Bresenham 兩種成像
   對同一條幾何會差 1px，2px + 1px 疊起來就是 3px。要「看起來是幾 px」就必須**單一成像**，
   不能靠兩層剛好對齊。
5. **改圖前先確認 PNG 是不是最新版。** 本例 PNG 的 mtime 比腳本早 16 分鐘，
   一度懷疑「圖與碼不一致」；用 `git diff HEAD -- <script>`（無差異）與稽核報告的圖斑數
   交叉驗證後才排除。**圖、碼、報告三者的時間戳與計數要能互相對上**。
6. **改資料欄位比改渲染邏輯安全。** 這次只動 `TOWNNAME/COUNTYNAME`（1 列），
   幾何、配色、統計全部不動，自檢數字一位不差；如果去改 ② 層的描邊規則，
   會影響全圖 368 個鄉鎮的線寬。
7. **「不需修改」也是一種結論，要說清楚。** 岡山那塊本來就是一般村里畫法，
   硬改反而會弄壞它 —— 交付時要把「為何這塊沒動」寫成可核對的數字（共邊 4.63 km、52% 已 1px）。
8. **留下可重跑的驗證腳本。** 診斷用的 5 支臨時腳本用完即刪（`_diag_*.py`），
   但量測方法寫進本文件；下次同類問題照這四招重做即可。

## 七、遺留問題（尚未處理）

- **全圖鄉鎮界實際成像 3~5 px**（`LINE_TOWNSHIP_PX = 2`）：② 層的 township 環與 ① 層
  同位的 1px 村里界**以不同演算法成像、錯開 1px 疊加**，所以比村里界粗很多，
  與 6 px 縣市界的差距偏小。這是使用者把鄉鎮界誤認成縣市界的**結構性成因**。
  若要全圖統一，可考慮「同位邊界只做一次成像」（例如 ② 層只畫 1px 參考線、
  再由線稿階段統一加粗到 2px），但會動到全圖 368 個鄉鎮，需另開一次改造。

  的規則（`fill_blank_islets_town_colors`）給它們上色，只需把縣市條件放寬即可；
  但使用者本次只要求改界線，未動填色。
