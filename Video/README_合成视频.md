# 把看板 PNG 合成 MP4（配樂版）—— 操作手冊

> 本文描述 `Video/tools/make_video.py` 與 `Video/tools/verify_video.py` 這條「圖片 → 影片」的鏈。
> 對象：已備好 `final/` 的 16 張看板 PNG 與 `final/MP3/` 配樂，要合成一支帶配樂的 MP4 的人。
>
> 撰寫時間：2026-10-05。基於當時的程式碼與目錄實況。

---

## 0. 這條鏈在整體管線中的位置

看板鏈（見 `README_批量做看板.md`）的終點是 `out/<id>_2560x1440.png`。
把其中挑出來的 16 張複製到 `final/`，就接上這條影片鏈：

```
  final/831.png … 1112.png        16 張成品看板（2560×1440）
  final/MP3/*.mp3                 6 首配樂
            │
            ▼
  ┌──────────────────────────────────────────────────────────────┐
  │ tools/make_video.py                                          │
  │  畫面：16 張各停留 N 秒，彼此 0.5s 交叉淡化（xfade）           │
  │  聲音：每首曲子只取指定區間，段與段 0.5s 交疊（acrossfade）     │
  │  兩者由同一組時間軸推導 → 音畫鎖死、不累積漂移                  │
  └──────────────────────────────────────────────────────────────┘
            │
            ▼
  out_video/臺北市長選舉1994-2022_2560x1440_配樂版.mp4
            │
            ▼
  tools/verify_video.py           對位質檢：確認每一段播的音樂正確
```

## 3. 時間軸：兩張表決定一切

全部在 `make_video.py` 開頭，改這裡就好。

### `TIMELINE` —— 每張圖停留幾秒

```python
TIMELINE = [
    ("831", 25), ("832", 32),          # 1994
    ("871", 15), ("872", 20),          # 1998
    ("911", 10), ("912", 18),          # 2002
    ("951", 23.5), ("952", 29.5),      # 2006  (原 20/25，按比例拉長)
    ("991", 11.75), ("992", 21.25),    # 2010  (原 10/18，同上)
    ("1031", 27), ("1032", 34),        # 2014
    ("1071", 23), ("1072", 33),        # 2018
    ("1111", 30), ("1112", 50),        # 2022
]
```

- 16 張合計 403s，扣掉 15 個 0.5s 交疊 → **成片 395.5s（6 分 35.5 秒）**。
- 2006＋2010 四張按原比例 `20:25:10:18` 拉長到 86s，是為了讓這一段畫面
  剛好等於 `2006.mp3` 取的 84s 配樂。

### `MUSIC` —— 哪一首、從第幾秒起、鋪在哪幾張圖上

```python
MUSIC = [
    ("1994", 93.0, 1, 2),      # 1:33 起 —— 覆蓋 1994
    ("1998", 2.0, 3, 6),       # 0:02 起 —— 覆蓋 1998 + 2002 四張
    ("2006", 102.0, 7, 10),    # 1:42 起 —— 覆蓋 2006 + 2010 四張
    ("2014", 20.0, 11, 12),    # 0:20 起 —— 覆蓋 2014
    ("2018", 15.0, 13, 14),    # 0:15 起 —— 覆蓋 2018
    ("2022", 90.0, 15, 16),    # 1:30 起 —— 覆蓋 2022
]
```

- 格式：`(mp3 檔名, 起始秒, 覆蓋第幾張起, 覆蓋第幾張止)`，圖號是 1-based 閉區間。
- **段內圖數可變**，所以同一首曲子能跨兩個年份連續播（1998+2002、2006+2010 就是這樣）。
- 每段該取多長，由 `durations()` 依畫面時間軸算出來，不用手填。

### 關鍵約定（別改）

| 約定 | 內容 | 原因 |
|---|---|---|
| 段邊界落點 | 該段最後一張圖 → 下一段第一張圖，**那個轉場的中點** | 音樂換曲與畫面轉場同時發生 |
| 相鄰段交疊 | 各向兩側多取 `FADE/2 = 0.25s`，用 `acrossfade` 接 | 換曲不爆音、對齊畫面 |
| 首段／末段 | 不向外多取 | 邊界就是片頭／片尾 |
| 片頭片尾 | 音樂整體淡入 0.8s、淡出 2.5s | 收尾不突兀 |

因為音訊長度與影片長度都由同一組 `TIMELINE` 推導，成片**音畫同長、無漂移**。

## 4. 用法

全部在 `Video/` 目錄下執行：

```bash
PY="C:\Users\Windows\.workbuddy\binaries\python\envs\default\Scripts\python.exe"

# 配樂版（預設）
"$PY" tools/make_video.py

# 六首曲子音量差很多 → 逐段響度拉平（推薦；實測段間極差 10.9dB → 0.3dB）
"$PY" tools/make_video.py --level

# 無聲版
"$PY" tools/make_video.py --no-music

# 換輸出檔名 / 提高畫質（crf 越小越好）
"$PY" tools/make_video.py --crf 18 --name 我的版本.mp4
```

可用參數：

| 參數 | 預設 | 說明 |
|---|---|---|
| `--out` | `Video/out_video` | 輸出目錄 |
| `--name` | `臺北市長選舉1994-2022_2560x1440_配樂版.mp4` | 輸出檔名 |
| `--crf` | `20` | H.264 品質，越小越好、檔案越大 |
| `--no-music` | — | 只出畫面 |
| `--level` | — | 逐段量 `volumedetect` → 補 `volume` 增益 → `alimiter` 限幅 |
| `--target-mean` | `-14.0` | `--level` 的目標平均音量（dB） |

輸出規格：`2560×1440 / 24fps / H.264 High / yuv420p / +faststart`，
音訊 `AAC 192k`（配樂版）。`+faststart` 讓 moov 前移，網頁與微信可邊下邊播。

## 5. 質檢：`verify_video.py`

```bash
"$PY" tools/verify_video.py "out_video/臺北市長選舉1994-2022_2560x1440_配樂版.mp4"
```

做法：在每一段的中點取 1 秒音訊，跟「源 mp3 對應位置」的波形逐點相減，
算平均誤差（MAE）與相對誤差。

- 相對誤差 < 30% 判為「同一段音樂」（AAC 是有損編碼，做不到逐位相等）。
- 實測 6 段相對誤差 5–17%，全部對位正確。
- 同時印出成片的 `Duration` 與各 `Stream` 規格。

## 6. 常見坑

| 症狀 | 原因 | 解法 |
|---|---|---|
| 音樂比畫面長／短 | 改了 `TIMELINE` 卻沒讓 `MUSIC` 跟著走 | 兩張表是一組的；改完先單獨跑一次 `durations()` 核對 |
| 某一首曲子特別大聲／小聲 | 各 mp3 母帶響度差很多 | 加 `--level` |
| 轉場處音樂爆音 | 直接硬接 | 已用 `acrossfade`；別改成 `concat` |
| 缺圖／缺音樂直接退出 | `make_video.py` 開頭會檢查 | 補齊 `final/` 或 `final/MP3/`，或改 `TIMELINE`／`MUSIC` |
| 想補 2002／2010 的專屬配樂 | 目前共用鄰年的曲子 | 把 mp3 放進 `final/MP3/`，然後在 `MUSIC` 拆成獨立兩段即可 |

> 一句話：**`TIMELINE` 決定畫面，`MUSIC` 決定聲音，兩者共用同一組轉場中點推導，改表就能重配。**
