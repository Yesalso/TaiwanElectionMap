# 桃竹苗總統看板 —— 快速重跑命令

> 對象：只重跑「桃竹苗總統線」（8 屆 × 1 版），**不碰**臺北市長線與北北基宜線。
> 所有命令都在 `D:\Windows\TaiwanElection\Video` 底下執行（PowerShell）。
> 背景與踩坑見 `docs/桃竹苗总统看板开发经验.md`。

---

## 一、2026-10-19 這次重跑做了什麼（結論）

起因：`assets/map/2016/map_tzmm.png`、`assets/map/2020/map_tzmm.png` 已修正
（2016 補回桃園／新竹沿海與縣界共 34,449 px；2020 補回新竹沿海 7,410 px），
但 `dist/` 與看板還是舊的。重跑後：

| 步驟 | 結果 |
|---|---|
| `build_assets.py --kind map --force` | 64 個地圖成品重生；**只有 2016／2020 的 `map_tzmm.png` 像素有變**，其餘 62 個位元組不同但像素完全相同 |
| `_gen_president_boards_tzmm.py` | 8 屆 meta／board.js 重建，票數與五大分區統計一致 |
| `render_boards.mjs --boards <8 場>` | 8/8 成功 |
| manifest 合併 | 40 筆（40 ok）——單場渲染會覆寫 manifest，已用舊檔併回 |
| `verify_layout.py` | 40 份報告 0 未通過（tzmm 的 L9 最小淨空 390 px、L10 13 px） |
| `dist/final/precident-tzmm/1/` | 8 張 `*_2560x1440.png` 已換成新 `board.png` |

> ⚠️ 市長線的 `dist/assets/map/{1994…2022}` 會被 `--kind map` 一起重寫（像素不變），
> 本次已還原成原檔。要完全避免，見第二節的「只做 tzmm」替代指令。

## 二、全量重跑（8 屆，最常用）

```powershell
$env:PYTHONIOENCODING = 'utf-8'      # 必要：主控台是 GBK，build_assets 會印 ✓ 與中文
Copy-Item dist/manifest.json "$env:TEMP\manifest.before.json" -Force

# 1) 素材去背（assets/map/<年>/*.png -> dist/assets/map/<年>/*.png）
python src/mapgen/tool/build_assets.py --kind map --force

# 2) 建 8 屆看板資料
python src/tools/_gen_president_boards_tzmm.py

# 3) 渲染 8 場（單場模式會覆寫 manifest，第 4 步併回）
node src/tools/render_boards.mjs --boards `
  1996-president-tzmm 2000-president-tzmm 2004-president-tzmm 2008-president-tzmm `
  2012-president-tzmm 2016-president-tzmm 2020-president-tzmm 2024-president-tzmm --scale 1

# 4) manifest 合併（以 board+scale 為鍵，重算 summary）
python -c "import json,os; p='dist/manifest.json'; old=json.load(open(os.path.join(os.environ['TEMP'],'manifest.before.json'),encoding='utf-8')); new=json.load(open(p,encoding='utf-8')); m={(r['board'],r['scale']):r for r in old['results']}; m.update({(r['board'],r['scale']):r for r in new['results']}); res=[m[k] for k in sorted(m)]; ok=sum(1 for r in res if r.get('ok')); out=dict(old); out['generatedAt']=new.get('generatedAt',old.get('generatedAt')); out['results']=res; out['summary']={'total':len(res),'ok':ok,'failed':len(res)-ok}; json.dump(out,open(p,'w',encoding='utf-8'),ensure_ascii=False,indent=2); print(len(res),ok)"

# 5) 版面驗證（期望：40 份報告，0 份未通過）
python src/tools/verify_layout.py

# 6) 同步平鋪成品（給視頻合成用）
#    平鋪目錄以現況為準：目前是 1/（舊筆記寫 2/，若你的機器上是 2/ 就自行替換）
foreach ($y in 1996,2000,2004,2008,2012,2016,2020,2024) {
  Copy-Item -Force "dist/boards/$y-president-tzmm/board.png" `
    "dist/final/precident-tzmm/1/${y}-president-tzmm_2560x1440.png"
}
```

### 不想動到市長線素材時（只重生 tzmm 兩張）

`build_assets.py` 沒有「只做某個檔名」的選項，但 `--year` 只會掃該年的條目。
最乾淨的做法是直接呼叫同一個去背函式：

```powershell
$env:PYTHONIOENCODING = 'utf-8'
python -c "
import sys; sys.path.insert(0, 'src/mapgen/tool')
from make_transparent import white_to_transparent as w
for y in range(1996, 2025, 4):
    for n in ('map_tzmm.png', 'map2_tzmm.png'):
        w(f'assets/map/{y}/{n}', f'dist/assets/map/{y}/{n}', threshold=12)
"
```

## 三、只重跑單一年份（改單張地圖時）

以 2020 為例（其餘 7 屆零觸碰）：

```powershell
$env:PYTHONIOENCODING = 'utf-8'
Copy-Item dist/manifest.json "$env:TEMP\manifest.before.json" -Force

python -c "
import sys; sys.path.insert(0, 'src/mapgen/tool')
from make_transparent import white_to_transparent as w
for n in ('map_tzmm.png', 'map2_tzmm.png'):
    w(f'assets/map/2020/{n}', f'dist/assets/map/2020/{n}', threshold=12)
"

python src/tools/_gen_president_boards_tzmm.py 2020
node src/tools/render_boards.mjs --boards 2020-president-tzmm --scale 1

# manifest 合併（同第二節第 4 步，貼一次即可）
python -c "import json,os; p='dist/manifest.json'; old=json.load(open(os.path.join(os.environ['TEMP'],'manifest.before.json'),encoding='utf-8')); new=json.load(open(p,encoding='utf-8')); m={(r['board'],r['scale']):r for r in old['results']}; m.update({(r['board'],r['scale']):r for r in new['results']}); res=[m[k] for k in sorted(m)]; ok=sum(1 for r in res if r.get('ok')); out=dict(old); out['generatedAt']=new.get('generatedAt',old.get('generatedAt')); out['results']=res; out['summary']={'total':len(res),'ok':ok,'failed':len(res)-ok}; json.dump(out,open(p,'w',encoding='utf-8'),ensure_ascii=False,indent=2); print(len(res),ok)"

python src/tools/verify_layout.py
Copy-Item -Force "dist/boards/2020-president-tzmm/board.png" `
  "dist/final/precident-tzmm/1/2020-president-tzmm_2560x1440.png"
```

## 五、注意事項

1. **地圖權威來源是 `assets/map/<年>/map_tzmm.png`**。`src/president/maps/<年>/2/` 是上游產物，
   2016／2020 目前比 `assets/` 舊；別用上游重繪覆蓋掉已修正的檔案。
2. `_gen_president_boards_tzmm.py` 只讀 `dist/assets/`，所以**先做去背再建看板**，順序不能顛倒。
3. `render_boards.mjs --boards` 只寫這幾場的 manifest；**沒有第 4 步合併就會丟掉其他 32 筆**。
4. 不要用 `--all`：會把市長線與北北基宜一起重繪（那些場次仍是舊樣式）。
5. 主控台若出現 `UnicodeEncodeError: 'gbk'`，就是漏了 `$env:PYTHONIOENCODING = 'utf-8'`。
6. `verify_layout.py` 若 L9／L10 FAIL，先看 `dist/boards/<id>/layout.json` 的地圖墨跡框，
   再確認 meta 的 `layout.map = {x:560, w:880}` 沒被改掉。
