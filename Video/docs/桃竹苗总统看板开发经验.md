> 日期：2026-10-19　範圍：總統選舉「桃竹苗」分區看板（桃園市／新竹市／新竹縣／苗栗縣）

> `src/tools/boardlib/assets.py`、`src/mapgen/tool/assets.map.json`

本文把「桃竹苗」這條線從零做出來的過程、踩過的坑、以及後續改版決策整理成一份可回看的筆記。

## 二、生成鏈路（桃竹苗專用）

資料與素材都已經備在 `src/president/` 底下，無需另外準備：

1. **素材拷貝**：`src/president/maps/<年>/{2,1}/桃竹苗*.png`
   → `assets/map/<年>/map_tzmm.png`（村里級）、`map2_tzmm.png`（鄉鎮級）。
   - 目錄 `2`＝村里級（得票率地圖2）、`1`＝鄉鎮級（得票率地圖）。
2. **配方登記**：`src/mapgen/tool/assets.map.json` 的 `map` 段，每個總統年補兩條：
   `map_tzmm.png`、`map2_tzmm.png`（how 預設 white，白底轉透明）。
   ★ 2026-10-21 起這兩條改成 `{"to": ..., "how": "whiteblack"}`：
     白底轉透明 **且** 純黑界線轉白線（見 §6-8）。
3. **去背**：`python src/mapgen/tool/build_assets.py --kind map --only map_tzmm.png --only map2_tzmm.png`
   → 成品落 `dist/assets/map/<年>/map_tzmm.png`、`map2_tzmm.png`。
   （`--only` 是為了不重寫市長線 / 北北基宜線共用的 `map.png` / `map2.png`。）
4. **建置**：`python src/tools/_gen_president_boards_tzmm.py`
   → `src/boards/<id>/meta.json` ＋ `dist/boards/<id>/{board.js, board.files.js}`
   （入口頁全場共用 `dist/boards/_entry/index.html`，2026-10-28 起不再逐場複製）。
5. **渲染**：`node src/tools/render_boards.mjs --boards <8 個 tzmm id> --scale 1`
   → PNG 落 `dist/dist_png/president-tzmm/<年份>.png`（`layout.json` 留在 `dist/boards/<id>/`）。
6. **驗證**：`python src/tools/verify_layout.py`（全量 32 場 PASS）。

> 資料來源是 `D:/Windows/TaiwanElection/Precident/<年>Precident/data/*縣市鄉鎮村里*.xlsx`
> 的「鄉鎮市區級別」工作表，過濾縣市 ∈ {桃園縣, 桃園市, 新竹市, 新竹縣, 苗栗縣}。
> 1996–2012 用「桃園縣」、2016 起「桃園市」，都要收。

## 三、踩坑 1：地圖是「近方形」，會撞到第 3 名高卡

**這條是整條線最關鍵的版面坑。**

- 北北基宜地圖是**直式**（3729×5596，ratio ≈ 0.667），contain 進預設主圖框
  （560–1580 × 196–1230）後，墨跡右緣只到 x≈1408，不影響右側。
- 桃竹苗地圖是**近方形**（4433×4716，ratio ≈ 0.94），contain 進同一個框後
  墨跡右緣到 **x≈1546**，而第 3 名高卡的左緣 ≥1478、區級圖欄從 x1440 開始
  → **整張壓上去**，`verify_layout` 的 L9/L10 會直接 FAIL。

**解法**：引擎開放 `Layout.map` 的逐場覆寫（`LAYOUT_OVERRIDABLE` 加 `'map'`），
桃竹苗 meta 寫：

```json
"layout": { "legend": {"disabled": true}, "map": {"x": 560, "w": 880} }
```

把主圖框收窄成 880 寬，實測墨跡右緣降到 **1432**、底部 **1172**，全部讓開。
（`layout.js` 檔尾的 `LAYOUT_OVERRIDABLE = ['legend', 'map2', 'map']`。）

## 四、踩坑 2：候選人欄位與政黨色

- xlsx 的候選人欄位名是 `姓名（號次）_得票數`（如 `柯文哲（01）_得票數`），
  用 `c.startswith(姓名) and c.endswith('_得票數')` 抓。
- 2000 宋楚瑜＝無黨籍（走灰），與北北基宜一致；`color.txt` 第 4 組宋親民黨橘
  只適用 2012/2016/2020。
- 副手黨籍（`viceParty`）是**登記當時**的黨籍，不是後來的黨籍：
  2016 陳建仁（蔡英文副手）、王如玄（朱立倫副手）與 2020 張善政（韓國瑜副手）
  登記時都是**無黨籍**。
- 副手行若為無黨籍，`layers.js` 的 `drawViceLine` 一律用 `Theme.parties.ind`
  的亮階標灰，**不沿用主候選人的政黨色**（否則無黨籍會被畫成藍／綠）。
- 1996 林洋港＝無黨籍、**新黨支持**：`recommendedBy="NSC"`，主卡標籤顯示
  「無黨籍 [新黨徽章] 新黨支持」（推薦文字比黨名小一級）。`used_shorts`
  要把推薦政黨一起併進去，否則 `party_nsc.png` 不會寫進 `board.files.js`，
  引擎只能退回抽象色塊。
- 得票數直接 `fillna(0).sum()`，得票率用「分區有效票」當分母重算。

## 五、踩坑 3：單場渲染會覆寫 manifest（已於 2026-10-25 修掉）

`render_boards.mjs --boards …` 以前只渲染指定場次，卻**把 `dist/manifest.json`
整份覆寫成只剩這幾場**。不想全量重跑時的標準做法是：備份 → 渲染 → 用
`(board, scale)` 為鍵把新舊 `results` 併回、重算 `summary`。

**現在渲染器自己併**：以 `board|scale` 為鍵，本次成功的記錄覆蓋同鍵舊記錄，
失敗則保留舊的成功記錄；尾行印「累计 N/N 笔」。要整份重寫才加 `--no-merge`。
所以上面那套手動備份／併回可以不用做了。

（桃竹苗 16 場第一次就是手動併回 48 筆；後來刪 `-map2` 後併回 40 筆。）

### 8. 黑界線轉白線（`how="whiteblack"`）

**需求**：看板底色是深色街景暗化背景，地圖上的**黑色**界線在深底上幾乎看不見，
希望改成白線。

**關鍵：不能分兩步做。** 「先黑轉白、再白底轉透明」是行不通的 ——
黑線轉白之後就成了白底遮罩要吃掉的對象，下一步會被一起清成透明，界線直接消失。
所以兩個遮罩必須在**同一次掃描**裡、都從**原圖**算出來：

```python
# make_transparent.py :: white_to_transparent_black_to_white()
white_mask = (r >= limit) & (g >= limit) & (b >= limit)   # 白底（原圖）
black_mask = (r == 0) & (g == 0) & (b == 0) & (a > 0)     # 純黑界線（原圖）
data[..., :3] = np.where(black_mask, 255, r)   # 黑線轉白，只改 RGB
data[..., 3]  = np.where(white_mask, 0, a)     # 白底轉透明
```

**黑線判準不帶容差**（精確的 `(0,0,0)`）：桃竹苗地圖的界線是 OpenCV
`cv2.line` 畫的（不抗鋸齒），實測整張圖只有精確純黑、沒有半灰過渡像素
（`max(R,G,B) <= 60` 的像素數 == 純黑像素數）。加容差反而會誤傷深色填色檔。

**落點**：

- `src/mapgen/tool/make_transparent.py` → 新函式 `white_to_transparent_black_to_white()`
- `src/mapgen/tool/build_assets.py` → 新配方 `how="whiteblack"`（`build_white_black()`）
- `src/mapgen/tool/assets.map.json` → 8 個總統年的 `map_tzmm.png` / `map2_tzmm.png`
  改成 `{"to": ..., "how": "whiteblack"}`；**市長線 / 北北基宜線的 `map.png`／`map2.png`
  維持 `white`**（共用同一批成品檔名，改了就會連帶改掉那兩條線）。

**副作用檢查**：黑→白只動 RGB、**不動 alpha**，所以地圖的墨跡框與
`map.profile` 完全不變 → `verify_layout` 的 L9／L10 淨空不受影響
（實測 40/40 PASS，L9 最小淨空 390 px、L10 13 px，與改動前相同）。

**實測效果**（2024，同一張看板做 A/B 像素比對）：

| 區塊 | 變亮像素 | 變暗像素 | 平均亮度 |
|---|---|---|---|
| 主圖（村里） | 79,724（佔 9.7%） | 0 | 99.7 → 104.8 |
| 右欄區級圖 | 13,284（佔 4.1%） | 0 | 107.4 → 110.9 |
| 主卡 / 其他區塊 | 0 | 0 | 不變 |

> 縮圖效果：主圖 4433 px 縮到看板 880 px（約 5 倍），白線會與兩側填色混色，
> 變成「該填色的亮色描邊」而不是刺眼的純白線 —— 這正是想要的效果。

### 7.0 2026-10-21：加出 5120×2880（2×）

需求：整體出 5120×2880 到 `dist/final/precident-tzmm/2/`，
**且不要在 `dist/boards/` 產生檔案**。

作法是 `--scale 2` + `--out` 指到暫存目錄，再平鋪改名：

```powershell
$tmp = "$env:TEMP\out_2x"
node src/tools/render_boards.mjs --boards <8 場> --scale 2 --out $tmp --manifest "$tmp\manifest.json"
foreach ($y in 1996,2000,2004,2008,2012,2016,2020,2024) {
  Copy-Item -Force "$tmp\president-tzmm\${y}_2x.png" `
    "dist/final/precident-tzmm/2/${y}-president-tzmm_5120x2880.png"
}
```

- **不是另一套版面**：引擎仍用 2560×1440 的絕對座標，`--scale 2` 只把整張乘 2
  （canvas 5120×2880），版面與 1× 完全一致。實測把 2× 縮回 1× 與原 1× 成品比對，
  平均差 1.6～1.9/255（差異集中在字與線的邊緣，屬重取樣相位差）。
- `--out` 指暫存目錄 → 正式 `dist/dist_png/` 不會出現 2× 檔；清單預設仍寫
  `dist/manifest.json`（不想混進 2× 記錄就加 `--manifest "$tmp\manifest.json"`）。
- 檔名是 **`president-tzmm/<年份>_2x.png`**（舊版寫 `board@2x.png` 是錯的）：`@` 會被 `/__save`
  的檔名消毒（只留 `A-Za-z0-9._-`）換成 `_`，POST 的名字跟 Node 端讀的名字
  對不上，2× 必 ENOENT。
- 每張約 15 MB（1× 約 4.5 MB）。
- 只改倍率時不需要重跑去背與建看板，直接渲染即可。

## 八、可復用的結論

1. **新分區線**照抄北北基宜生成器，改 `REGION_COUNTIES`／`COUNTY_ORDER`／
   `REGION_LABEL`／地圖檔名，別動候選人名單。
2. **近方形地圖**先量墨跡右緣（讀 PNG alpha 的 bbox，換算成看板座標），
   超 1440 就要用 `meta.layout.map` 收窄主圖框，靠 `verify_layout` L9/L10 把關。
3. **政黨徽章**源圖底色非純白時（滿版青／白底黑圓），一律 `CircleRecipe` 填
   識別色再內切圓；「有沒有標章」由 `slide.js` 的 `PARTIES_WITH_MARK` 決定。
4. **單場渲染**必備份＋合併 manifest，別讓它吞掉其他場次記錄。
5. **色卡要不要畫**是一刀切的視覺決策，改 `CandidateLayer` 那三段即可；
   幾何與驗證鏈不用動。
6. **副手黨籍**以登記當時為準（2016 陳建仁／王如玄、2020 張善政皆無黨籍）；
   顯示時無黨籍固定標灰，不要沿用主候選人的政黨色。
7. **地圖改了就要重跑整條鏈**（去背 → 建看板 → 渲染 → 併 manifest → verify）；
   只換 `assets/map/*.png` 而不重跑 `build_assets`，`dist/assets` 仍是舊檔，
   看板不會變。快速指令見 `docs/桃竹苗看板_快速重跑命令.md`。
8. **深色底上的黑界線要轉白**：轉換必須與「白底轉透明」放在**同一次掃描**裡
   （兩個遮罩都從原圖算），分兩步做會把剛轉白的線一起清成透明；
   黑線判準用**精確的 (0,0,0)**、不加容差（OpenCV 畫線本來就沒有抗鋸齒邊）。
9. **只改桃竹苗的素材就用 `build_assets.py --only <原始檔名>`**：
   市長線 / 北北基宜線與桃竹苗共用 `assets/map/<年>/map.png` / `map2.png`，
   `--kind map --force` 會把它們一起重寫。
