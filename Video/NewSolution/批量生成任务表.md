# 批量生成任务表 —— Batch Board Generation

> 依据：`NewSolution/README.md`（设计规格）+ 2026-10-04 实际代码与目录盘点。
> **本表的目标是「批量生成能力」，不是「让 2018 出一张图」。**
> 单场能出图只算中间里程碑，最终验收一律以 `tools/build_all.py` 为准。

---

## 0. 目标与总验收（批量生成的 DoD）

**一句话**：一条命令从干净工作区产出 N 场 × M 倍率的看板 PNG + `manifest.json`，无人值守、可回归、可重现。

| # | 验收条件 | 判定方式 |
|---|---|---|
| A1 | `python tools/build_all.py --all --render --scales 1,2` 一次跑完 | exit code 0 |
| A2 | 产出 N 场 × 2 张 PNG + `out/manifest.json` | 文件存在、数量对 |
| A3 | **新增一场 = 只加 `meta.json` + `source/` 素材，JS/Python 零改动** | 用假场次实测 |
| A4 | 单场失败**不中断**整批；末尾印摘要（成功 N / 失败 M / 跳过 K） | 用坏输入实测 |
| A5 | `python tools/verify_all.py --all --check` 三层验证全过 | exit code 0 |
| A6 | 相同输入 → 相同 SHA256 | 连跑两次比对 |
| A7 | v1 规模：6 县市 × 4 届 ≈ **24 场** | 实际产出计数 |

> 当前状态：**A1–A7 全部未达成**（`build_all.py` 不存在；2018 的 `out/` 是空的；`out/` 基准与 `manifest.json` 全无）。

## 1. 必先拍板的关键决策

### D0 — 引擎归属：往哪一套收敛？（阻塞全部任务）

现在工程里**并存两套引擎**，必须先决定留哪一套，否则后续每一步都会做成双份。

| 选项 | 内容 | 代价 | 与 README 一致性 |
|---|---|---|---|
| **A（推荐）** | 把泛化逻辑**原地**并回真引擎（`_engine/js/core|model|render`，`layout.js` 14.5 KB），保留 2014 现有版面 | 工作量大；需重写 model + slide + layers 的少数硬编码点 | ✅ 符合不变量「2014 逐像素相同」 |
| **B** | 以 2018 的简版原型（`_engine/js/*.js`，`layout.js` 2.3 KB）为新基准 | 2014 既有版面作废、需重做视觉与回归基准 | ❌ 破坏「2014 零差异」基准 |

**推荐 A**：2014 的既有 PNG 是已交付物，`layout.js` 的 14.5 KB 是真实版面，简版只是原型。
**若选 B**，本表的 T1–T5、T7 需整体改写。

> 决策未定前，T1–T5 不要开工。

## 4. 关键依赖链（一句话）

```
D0 决策
  └─ T6 渲染器 ── T7 基准 ── T1..T5 引擎统一 ── T9..T13 资产池 ── T16 build_all ── T17 verify_all ── T21 24 场
                        └─ T8 hook ────────┘
```

**两处绝对不能动的顺序**（README 已写、实作时被跳过）：
1. **T7 基准 必须在 T1 引擎改动之前**——先有「改坏了能证明」的能力，再去改引擎。
2. **T6 渲染器 必须先于 T16 build_all**——批量是渲染器的循环，不是另写一套。

## 5. 风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| **引擎两套并行未收敛** | 高（后续全部工作翻倍） | M0 先拍板，T5 一次性清干净 |
| **24 场素材凑不齐**（市徽/党徽） | 高 | T12 `pool/` + `build_all` 开局列缺件，别等渲染才报错 |
| **SHP 只有民国 111 年版** | 中 | 1993/1997 等年份排不进 v1；`region.shp` 逐场指定 |
| 字体缺字 | 中 | manifest 记字体清单；`verify_all` 报警告不报错 |
| Edge 版本更新致像素差异 | 低 | manifest 记版本；跨版本只比「区块内」 |
| 2× PNG 体积（≈600 MB） | 低 | 产物进 `.gitignore`；日常只出 1× |
